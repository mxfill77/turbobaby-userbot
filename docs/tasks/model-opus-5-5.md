2. Внести правки по таблице выше. Только живые файлы, снимки не трогать.
3. Поправить тесты, которые пинят старый id как решение владельца — они часть правки, а не помеха:
   `test_pc_orchestrator.py` (EXECUTOR_MODEL, argv `--model`, `_norm_model_id`, METRICS),
   `test_dispatch_notify.py` (строка METRICS), `test_env_value_leak.py` (фикстура THINKER_MODEL).

4. Прогнать те же тесты после и назвать числа. Красное — чинить, не обходить.
5. Сказать отдельной строкой, какие файлы изменены и сколько строк в каждом.
6. Демон не перезапускать. Написать, что правка вступит в силу на следующем его рестарте.
7. Последним действием — отчёт в `docs/artifacts/` за 23.09, с отдельной строкой ровно со словом
