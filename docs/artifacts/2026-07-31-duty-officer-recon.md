### 8. Признак, по которому дежурный отличит одно от другого

Признак — **не класс и не подстрока в команде**. Класс (`env`, `delete`, `py_write`) внутри себя
делится на оба списка (таблица выше), а подстрока — прямой запрет свода §5 «судить по ДЕЙСТВИЮ,
а не по подстроке». Собственная проба этой сессии — доказательство: команда, ВНУТРИ которой
лежала строка регулярки со словами удаления, получила карточку класса `delete` с
`Объект: -`, хотя считала строки лога.

**Признак — тройка полей самой карточки, и все три обязаны быть заполнены:**

```
ОБЪЕКТ (что именно) · НАПРАВЛЕНИЕ (чтение | запись | снятие) · ЗОНА объекта
```

**Бесспорно** — только при совпадении ВСЕХ четырёх условий:

1. **ОБЪЕКТ НАЗВАН** — путь, PID, имя таблицы, хост, id деплоя. Пусто, `-`, `.`, `x`, огрызок
   вроде `settings.` — карточка **дефектная**, и дежурный её не закрывает: он не знает, что
   одобряет. По замеру это отсекает 43 карточки из 88 сразу.
2. **НАПРАВЛЕНИЕ = чтение** — либо запись/удаление, но **объект целиком лежит во временной зоне**
   (`tmp/`, `%TEMP%\claude\**\scratchpad`, `/tmp/`) и создан этим же прогоном.
3. **ЗОНА объекта — своя**: рабочее дерево `D:\turbobaby-bot` или временная папка. Не чужое
   дерево, не VPS по ssh, не `~/.claude` вне `memory/`.
4. **Вето не сработало** (ниже).

**НИКОГДА не автоматом — вето поверх всего, «да» на класс его не снимает:**

- **деньги** — любая транзакция, баланс, счёт;
- **живые таблицы парка и CRM** — `gspread`, `script.google.com`, лист Apps Script, `clasp` в
  любом виде;
- **клиентский контур** — `suggest.py`, ворота контура, `moderation_ipc.set_decision(..., "ready")`
  (это отправка живому клиенту), клиентские черновики;
- **выкатка прода** — `clasp deploy/undeploy/push`, `git push --force`, `git reset --hard`,
  self-update демона;
- **удаление вне временных папок** — включая файлы состояния в корне репо
  (`cowork_log.spool`, `*.lock`, `*.state.json`, `pc_ask_*.marker`);
- **секреты** — `.env` и `.env.*` на чтение И на запись, `*.session`;
- **живые процессы и планировщик** — снятие PID, `schtasks`;
- **выход за пределы проекта на запись** — `D:\foreign\*`, ssh на VPS.

**Что дежурному для этого признака НЕ хватает по факту** (не предложение, а замер):
поля `Объект` нет в `pretool_guard.log` (`_log_line` `:2091-2098` его не берёт), а там, где оно
есть, оно негодно в 43 случаях из 88. Значит признак сегодня вычислим **только по
`pc_ask_<tid>.marker` и по `item["what"]` из очереди** — то есть только на headless-полосе.
На интерактивной полосе дежурный признак вычислить не может и ответить тоже не может (§2.A).
