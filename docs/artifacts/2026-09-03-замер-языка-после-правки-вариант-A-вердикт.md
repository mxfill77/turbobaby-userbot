# Замер языка ПОСЛЕ правки, вариант A: вердикт приёмки — 0 провалов из 20

**Исход в одной строке.** На кандидате `27d0f8d` EN-набор даёт **0 языковых провалов из 20
единиц** (4 круга × 5 EN-кейсов) при живой цене. База до правки — **3 из 20** (`c97a30d`,
[`2026-09-03-база-языка-при-живой-цене-число-провалов.md`](2026-09-03-база-языка-при-живой-цене-число-провалов.md)).
По объявленному ЗАРАНЕЕ правилу п.6 это **доказательство правки**: при прежней частоте 0.15 на
единицу ноль из двадцати выпадает с вероятностью `0.85²⁰ = 0.0388` — **3.9%**, «примерно четыре
случая из ста».

Ось: бизнес (клиентский цикл через тренажёр). **Кода не правилось ни байта** — эта задача только
мерила; правка лежит коммитом `27d0f8d` от предыдущего захода (§9).

## 6. Условия замера сравнимы с базой — и это доказано числом, а не словом

«0 из 20» ничего не стоит, если цена в этот раз не пришла: замер без цены уже давал 0 из 20
02.09 именно потому, что русского в ответе почти не было. Поэтому условия пересчитаны тем же
кодом по обоим файлам единиц (`analyze_after.py`, функция `code_inserts` перенесена из
`_scratch_en_live/analyze.py` **дословно**, иначе числа несравнимы):

| условие | база `c97a30d` | кандидат `27d0f8d` |
|---|---|---|
| чек «строка J дословно» | зелён **12**, красен 0, неприменим 8 | зелён **12**, красен 0, неприменим 8 |
| чек «цена цифрой» | зелён **12**, красен 0, неприменим 8 | зелён **12**, красен 0, неприменим 8 |
| дословных вставок кода в ответ | **244** в 16 единицах из 20 | **244** в 16 единицах из 20 |
| ↳ из них **русских** | **52** | **52** |
| ↳ кириллических букв внутри вставок | **1324** | **1324** |
| русские вставки по видам | 48 строк J + 4 доставки | 48 строк J + 4 доставки |
| русские вставки по кейсам | 13: 40 · 16: 8 · 8: 4 | 13: 40 · 16: 8 · 8: 4 |

Совпадение **посимвольное по всем шести строкам условий**. Это не совпадение-удача: вставки
собирает КОД детерминированно из одного и того же слепка цены (`snapshot_on='2026-09-02'`, те же
модели и те же суммы), а правка тронула только промпт. Значит русского текста в ответ по-прежнему
льётся столько же, сколько на базе — и всё равно ноль провалов.

## 8. Вердикт приёмки по правилу, объявленному ЗАРАНЕЕ (п.6)

Правило задания дословно: база — три провала из двадцати; **ноль из двадцати считаем
доказательством правки**, потому что при прежней частоте такое случается примерно в четырёх
случаях из ста; один-два — улучшение НЕ доказано; три и больше — вариант A не сработал.

```
база          : 3 провала из 20  → частота на единицу 0.1500
P(0 из 20 | прежняя частота) = (1 − 0.15)^20 = 0.0388 = 3.9 %
кандидат      : 0 провалов из 20
```

**ВЕРДИКТ: ноль из двадцати — правка варианта A ДОКАЗАНА объявленным правилом (p = 3.9 %).**

Слова «стало лучше» здесь не заменяют арифметику, а следуют из неё: правило было названо до
замера, знаменатель и частота взяты из базы, а не подогнаны. Замер неполным не был — 20 единиц
из 20, потолок не срабатывал ни разу, `unknown` — 0.

## 10. Урок в тренажёр — с источником и датой

Формулировка, готовая к переносу в правила тренажёра (сам файл `trainer_rules.json` этой задачей
**не правился**: она меряет, а не правит):

> **«Русские строки, которые вставляет в ответ КОД (канон строки J, строка доставки), — это
> данные, а не сигнал сменить язык: EN-клиенту вся собственная речь остаётся английской, включая
> приветствие; вставки не переводить и не переписывать.»**
> **Источник:** замер языка после правки варианта A, кандидат `27d0f8d`, 20 единиц EN-набора при
> живой цене — 0 провалов из 20 против базы 3 из 20 при посимвольно тех же 52 русских вставках
> кода (1324 кириллические буквы). **Дата:** 03.09.2026.

Почему урок стоит держать при себе, а не считать закрытым навсегда: механизм НЕ доказан.
Русские вставки на месте в том же количестве, изменился только промпт — значит правило работает
на послушании головы инструкции, а не на устранении причины.

## 11. Честные остатки

- **Механизм не доказан.** 0 из 20 доказывает ЭФФЕКТ правки по объявленному правилу, но не
  утверждает, что причиной базовых провалов были русские вставки: они остались (52 шт., 1324
  буквы), а провалы исчезли. Контрфакт «англоязычный канон строки J» этим замером не ставился.
- **3.9 % — это не ноль.** Правило приёмки принято заранее и выполнено, но один замер из двадцати
  единиц не исключает возврата провала: при истинной частоте даже 5 % ноль из двадцати выпадает в
  36 % случаев. Устойчивость проверяется повтором на другом вечере, а не пересчётом этого.
- **Знаменатель кейса 15.** Цены в нём нет по замыслу (дат в диалоге нет), то есть 4 его единицы
  мерили язык на промпте БЕЗ ценового блока. Если считать только единицы с ценой в промпте,
  знаменатель 16, и число — **0 из 16** против базовых 3 из 16. Оба верны, знаменатель назван.
- **Дымовой русский круг — один круг, не четыре.** «Русский путь не сломан» снято на 10 единицах,
  а не на 40; для базы русского пути такого замера не делалось вовсе, сравнивать не с чем.
- **Замер воспроизводится:**
  `venv/Scripts/python.exe _scratch_lang_a/run_units.py en en 4 1500` (сам замер, прерываемый),
  `… run_units.py ru_smoke 1,2,3,4,5,6,7,10,11,12 1 900` (дымовой русский круг),
  `… analyze_after.py` (весь разбор §§5–8 одним кодом).
