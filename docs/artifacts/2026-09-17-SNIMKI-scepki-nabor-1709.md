**Что мешает отдать набор человеку прямо сейчас — три вещи, из них одна настоящая преграда:**

1. **Преграда: живой набор не подключён к показу и тапу.** `exam_show.py --live` открывает только `--freeze`,

   набора, а журнал вердиктов и стол у наборов общие. Значит, тап по живому кейсу лёг бы вердиктом кейсу тренажёра
   с тем же номером. Сейчас человек может только **читать** карточки с CLI (`--live --card --case N`), а вердикт
   положить ему некуда.
2. **Кейс 23 без снимка**: одна единица, ≈200 с (§2).

   кода. Когда показ подключат, сверять снимок придётся с версией кейса, а не всего набора (63-q §1).

**Вывод:** к чтению карточек с CLI набор готов на **11 из 12**. К прогону человеком с вердиктами **не готов**, пока
