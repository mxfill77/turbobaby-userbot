## Что изменилось (одна операция, две строки смысла)

`moderation_core.py:485` — новая `may_write_rule(username)`; `remember_rule` (теперь :507) судит
право ею вместо `suggest.is_approver`:

```python
def may_write_rule(username):
    if not suggest.APPROVER_USERNAMES:
        return False            # ← пустой список = НИКОМУ (было: «можно любому»)

```

Членство в непустом списке по-прежнему судит `suggest.is_approver` — второй копии нормализации
`@`/регистра не заведено, значит ей нечем разъехаться с оригиналом. На непустом списке поведение
БИТ В БИТ прежнее; изменился ровно один вход — пустой список.
