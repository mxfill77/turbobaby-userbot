# ГАРД: поток подтверждений в bypass-режиме — 23.09.2026

**Вопрос владельца:** «Я сделал bypass permissions — что столько запросов???»

## Ответ одной строкой

Окна рисовал не Claude Code, а PreToolUse-хук репозитория `pretool_guard.py`
(`.claude/settings.json` → `hooks.PreToolUse`). Режим bypass снимает правила разрешений

## Послабления (`pretool_guard.py`; тесты — класс `TestPromptFlood2309`)

1. **Поддомены `t27.ai`** (`_NET_ALLOWED_SUFFIXES`, `_net_host_allowed`) и точным именем публичный
   бэкенд сайта `trios-agent-server-production.up.railway.app`. Суффикс только у t27.ai.
2. **Адрес из переменной того же вызова** (`B=https://app.t27.ai/…; curl $B`): подставляется, если
   присваивание — отдельный оператор с единственным литералом. `for`/`read`/`+=`/`${B…}`,
   env-префикс, два значения, свой `IFS` — не подставляются.
3. **`-o /d/tmp/…`** (MSYS-путь Git Bash) переводится в `D:\tmp\…` до проверки зоны.
4. **Шелл-запись** (`>`, `Out-File`, `Copy-Item` …) судится теми же зонами, что Write; проверяется
   КАЖДАЯ цель; секрет внутри зоны спрашивает.
5. **Профиль вне `.claude`**: `<CLAUDE_CONFIG_DIR>\projects\<репо>\memory\<файл>` и
   `…\<сессия>\workflows\scripts\*.js`. Стенограммы, `settings.json`, `hooks\` — спрашивают.
6. **`curl -m N | python -c …`**: сканер python читал таймаут curl как `python -m 60`; флаги теперь
   считаются с первого интерпретатора.
7. **`cargo build/check/test/clippy/fmt/doc/tree/metadata/--version…`** — зелёные, если КАЖДЫЙ
   сегмент команды — такой cargo, `cd`/смотрелка или `export PATH="$HOME/.cargo/bin:$PATH"`.
   **Решение, о котором надо знать:** `cargo test` исполняет рабочее дерево (build.rs, тесты),
   включая незакоммиченное — это то же доверие, что запись в `D:\turbobaby-bike-bot` (12.09).
8. **`-D -`, `-f`, `-t` у curl** больше не читаются как `-d`/`-F`/`-T`.

## Проверка

- `test_pretool_guard` + модули, импортирующие гард (`test_card_*`, `test_env_value_leak`,
  `test_exec_position`, `test_guard_action_not_text`, `test_mark_vs_address_pc`, `test_owner_mute`,
  `test_probe_isolation`, `test_pc_orchestrator`) — **1920 тестов, все зелёные**.
- Состязательная проверка, проход 1 (workflow, 3 атакующих): зоны записи дали находки выше
  (`.git` корней, запись без пробела/MSYS/UNC); сеть и исполнение вернулись пустыми.
- Проход 2 (workflow) не состоялся: все три агента остановлены до первой пробы — **не зачтён**.
- Самопроверка (`tmp/prompt_flood_2309/test_probe_self.py`, 58 попыток обхода по сети и
  исполнению): нашла `| sh`, адрес без схемы, прокси/перенаправления, соседей cargo и его
  env-префикс — всё закрыто; после правки **0 нарушений** «обязано спрашивать». Оставшиеся новые
  молчащие — тот же разрешённый хост (регистр, точка в конце, порт, путь из переменной,
  `--url-query`, `-H @файл` к нему же).
