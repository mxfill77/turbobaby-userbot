## Корень «размножения» сред (почему их 8)

`claude rc` регистрирует НОВУЮ среду на КАЖДЫЙ старт. Ливнесс-проба супервизора
(`LIVENESS_MAX_AGE=1200с`) перезапускает rc-server примерно каждые ~20–45 мин → каждый рестарт
плодит новую среду и осиротевает предыдущую. Чистка удалением — это «беговая дорожка»: без
правки причины (реже рестартовать / переиспользовать среду по стабильному bridgeId) мёртвые
будут копиться снова. На каждой новой среде повторяется и `400 GitHub repository access check
failed` (session-creation блокатор).
