## ГЛАВНОЕ ОДНОЙ СТРОКОЙ

**Читатели НЕ расходятся по колонке масла — у обоих это колонка I, и это доказано тремя
независимыми адресами, включая ответ самого моста `Лист1 | I16`. Расходятся они по ТЕКУЩЕМУ
ПРОБЕГУ и по ВРЕМЕНИ.** Читатель-1 берёт пробег, названный человеком в ту минуту (настоящий, но с
датой), читатель-2 при отсутствии своего одометра **подставляет вместо пробега `max(I/J/K/L)`** —
то есть один из тех самых регистров, просрочку которых он же и считает. Отсюда встроенный
ложно-отрицательный исход: **наибольший регистр не может быть просрочен ПО ПОСТРОЕНИЮ.**

Числом раскол измерен и он **без единого исключения: 29 байков из 38 не имеют штампа одометра — у
всех 29 `current_km` равен `max(I..L)` ТОЧНО; 9 байков штамп имеют — у всех 9 НЕ равен.** 38 из 38.

## п.4 — ДВА СОВПАДЕНИЯ: ИСХОД ВТОРОЙ, **ПОДСТАНОВКА РЕГИСТРА ВМЕСТО ПРОБЕГА**

Вопрос стоял так: у 3503 и 4729 «текущий пробег» живого чтения равен регистру масла ровно —
это настоящее значение листа, подстановка или неизвестно? **Ответ: подстановка.**

**Адрес механизма:** `splinter.py:2413-2415` — фоллбэк `max(I/J/K/L)` в `_odo_current`.
У 3503 заполнена одна клетка I=29300 (J/K/L пусты) → `max` = 29300 = I. У 4729 заполнены I=J=20400
→ `max` = 20400 = I. Совпадение не случайное: это буквально одно и то же число, прочитанное дважды.

**Доказательство не рассуждением, а замером по всему парку** (38 байков, `park_full.json`):

| группа | байков | `current_km` == `max(I..L)` |
|---|---|---|
| штамп одометра ЕСТЬ (`odometer_confirmed_utc` с датой) | **9** | **0 из 9** |
| штампа НЕТ | **29** | **29 из 29** |

Раскол **38 из 38 без исключений** — ровно тот, который предсказывает код: есть свой одометр →
ветка (1), нет → ветка (2). Контрпример в пользу ветки (1) тоже есть и он сильный: у
`NMAX 155CC BLACK GOLD PHUKET 4255` `current_km` = **25906**, а `max(I..L)` = **29300** — «текущий»
МЕНЬШЕ максимального регистра, чего фоллбэк дать не может в принципе.

**Прямая улика по 3503, из лога** (`splinter.log`, 2026-07-31 05:58:27):

```
→ ТО фаза2 → подтверждение Пыму: CB 650R BLACK 3503 done=['chain'] odo=33974 (tok=6)
```

Пробег байка, **подтверждённый человеком** 31.07, — 33974. «Текущий пробег», который живое чтение
показывает 20.09, — **29300**. Пробег не убывает; значит 29300 — не пробег.

**Следствие, которое больше самого вопроса.** У 24 байков из 38 регистр масла и есть тот самый
максимум, то есть `I == «текущий пробег»`. Для них остаток до срока равен интервалу ТОЧНО, и
**масло не может быть просрочено ни при каких данных**. Живое чтение 20.09 нашло просроченное масло
ровно у трёх байков — и все три из девятки со штампом одометра. Ложно-отрицательный исход тут не
случайность конкретной клетки, а устройство.

## ЧТО С ЭТИМ ДЕЛАТЬ (не сделано, предложено — чинить заданием не велено)

Само собой не рассосётся: у 29 байков из 38 «текущий пробег» — это регистр, и чем дольше байк не
попадает в переписку с называнием одометра, тем увереннее он числится «в норме». Дешёвая правка —
не менять фоллбэк (он честен: «одометр на момент замены»), а **назвать его вслух в выдаче**: поле
