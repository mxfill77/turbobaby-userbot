## 3. Остаток потерян или отображается неверно

**Строки транзакций — целы; потерян ЯКОРЬ остатка, и это потеря на машине.**

- Лист транзакций **append-only** и баланс в нём не хранится: `computeBalance_(group)`
  (`BotData.js:662-682`) каждый раз **суммирует строки** с точным совпадением метки,
  пропуская `status=void`. Затирать там нечего — и запись −7000 ничего не затёрла.
- Но в листе **нет ни одной строки старше 27.07**. Money Cashflow = −7000 ровно потому,
  что строка −7000 у него **единственная**.
- Прежние 12992 THB и 150 EUR жили **только в кэше** `wallet_cache.json`, и он перезаписан.

**Доказательство, что лист потерял историю (а не «её там не было»):**
`2026-06-17 07:11:11 [INFO] splinter: → moves=[(2990, 'THB'), (500, 'EUR')]` — движение
+500 EUR реально проводилось. Будь эта строка в листе, EUR обязан был бы появиться в
`get_balance`. Его там нет ни в одном кошельке. Значит строки до 27.07 из листа исчезли.

**Прежний остаток подтверждён машинным фактом** — `git show 88db1ae:wallet_cache.json` (23.07):
```
{"Money Cashflow": {"THB": 18037.0, "EUR": 150.0}, "Самоорганизация": {"THB": 46.0}}
```
EUR 150 держался давно: `2026-06-04 [WARNING] splinter: 🔎 АУДИТ ... «ยอดคงเหลือ: 2 799 ฿ · 150 EUR · 1 паспорт»`.

## 4. Причина — «Deposit» ни при чём. Файл:строка

Слово `Deposit` **не влияет ни на кошелёк, ни на тип**: кошелёк берётся из чата, не из текста.

```
splinter.py:2003    wallet = group_label(chat_id)
splinter.py:174-181 GROUP_NAMES = { -1003873906891: "Money Cashflow", ... }
```

Настоящая механика сброса — три звена:

1. **`splinter.py:2311-2312`** — после записи строк баланс берётся у Bridge:
   ```python
   wallet_bal = wallet_cache.get_balance_with_fallback(
       wallet, bridge.get_balance(group=wallet).get("balance", {}))
   ```
2. **`wallet_cache.py:88-90`** — непустой ответ Bridge **приоритетен** и пишется в кэш:
   ```python
   if bridge_balance:
       save_wallet_balance(wallet, bridge_balance)
       return bridge_balance
   ```
3. **`wallet_cache.py:68`** — сохранение **замещает словарь валют целиком**:
   ```python
   data[wallet] = {k: float(v) for k, v in balance.items() if v is not None}
   ```

Пока у Money Cashflow в листе не было ни одной строки, `computeBalance_` возвращал `{}` —
пустой ответ, срабатывал fallback, и владелец видел кэшированные 12992 THB / 150 EUR.
**Запись −7000 стала первой строкой кошелька** → Bridge впервые ответил непусто
(`{"THB": -7000}`) → сработал приоритет Bridge → кэш заместился целиком: THB стал −7000,
а **EUR исчез, потому что его ключа в ответе не было** (строк в EUR в листе нет).

Итог: запись сработала штатно и лишь **обнажила** уже пустой лист, а заодно уничтожила
единственную копию прежнего якоря. Дефект-класс: **производная величина молча затирает
хранимую**; валюта, отсутствующая в ответе, обязана переживать запись, а не пропадать.

## 5. Что восстанавливать и как — НЕ ВЫПОЛНЕНО, на решение владельца

**Путь A (предпочтительный) — вернуть историю листа.**
Google Sheets → Bot Data → лист транзакций → «Файл ▸ История версий»: посмотреть, когда лист
опустел (между 15.07 и 27.07 — 15.07 в Money Cashflow ещё шёл якорь «Баланс считаем отсюда»),
и восстановить версию. Баланс пересчитается сам: он всегда сумма строк. Правка данных руками
не нужна.

**Путь B (если история невосстановима) — один якорь через бота.**
Отправить в группу Money Cashflow (`-1003873906891`) доверенным автором **ОДНО** сообщение,
называющее **обе валюты**:

```
Зафиксируй баланс: 5992 THB и 150 EUR
```

Что сделает код (`splinter.py:2073-2102`): посчитает `adj = target − текущий` и допишет
строки-поправки `+12992 THB` и `+150 EUR` категории `adjustment`, затем запишет якорь в кэш.
Лист останется append-only, поправка будет видна в аудите.

- 5992 = 12992 − 7000: запись −7000 **законна и уже в листе**, её вычитать не нужно.
- ⚠️ **Обязательно одним сообщением с обеими валютами.** Если назвать только THB, якорь снова
  станет THB-only и EUR пропадёт вторично — ровно по `wallet_cache.py:68`.
- Число 12992 — со слов владельца; машина его копии не имеет (кэш перезаписан атомарно
  `os.replace`, бэкапа нет). Ближайший машинный ориентир — 18037 THB на 23.07.

**Путь В (код, отдельной задачей, не сейчас):** в `get_balance_with_fallback` сливать, а не
замещать: `{**cached, **bridge_balance}`. Безопасно: `computeBalance_` отдаёт валюту даже с
нулевой суммой, если строки есть; отсутствие ключа означает «строк нет вообще», и кэш по этой
валюте — единственный источник.
