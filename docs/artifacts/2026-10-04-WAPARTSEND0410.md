## Устройство

1. **Вложение из сверки** (`attach_of`). Берётся `ModelAdapter.last["tools"]` того же вызова через обёртку модели
   `_Probe`. PDF прикладывается, если сошлось всё: сверка `done`; ровно один `doc_id` среди принятых `contract`;
   `rental` = fact на тот же байк; `contract_pdf` = fact с `id == pdf_id` договора, 64-значным sha256 и размером.
   Если не сошлось, в таблицу `attach` пишется причина: «сверка не завершена», «договор не принят сверкой:
   ambiguous/empty», «аренда не подтверждена», «байк аренды и договора расходится», «PDF не принят: refused»,
   «PDF не этого договора», «contract_pdf не звали». В таблице только метаданные.
2. **Две части.** Текст — прежний `drafts.state`. PDF — строка `pdf_parts`: `wait` → `claimed` (захват, байты из
   `contract_pdf` в момент отправки, сверка sha256) → `sending` ДО `door.send_media` → `sent`/`not_sent`/`unsure`.
   PDF зовётся только после `sent` текста. Если текст `not_sent` или `unsure`, дверь PDF не вызывается («файл без
   текста не уходит»). Если sha256 не совпал, PDF получает `not_sent` с обоими отпечатками. wamid PDF пишется в
   `outbox`, поэтому эхо PDF не ставит клиента на паузу.
3. **Рестарт.** PDF `sending` → `unsure`. `claimed` → `not_sent` (двери не было). `wait` при решённом тексте →
   `not_sent` с причиной. Ни одна часть на старте не повторяется (тест).
4. **«Дослать PDF»** (`press_pdf`, кнопка несёт номер попытки). Работает при тексте `sent` и PDF `not_sent`;
   кнопка прежней попытки отвечает «уже решено». При PDF «неизвестно» сначала сверяются статусы провайдера
   (`wa_inbox`, `msg_type='status'`, sent/delivered/read, после попытки; наши wamid исключены):
   - доставка подтверждена → PDF `sent` с wamid статуса, дослать нельзя;
   - не подтверждена → `need_permit` со словами «повтор может дать ВТОРОЙ такой же PDF»; дослать можно только
     действием `pdf_risk`, разрешение пишется (`permit=1`);
   - статусы не прочитаны → дослать нельзя.
5. **«Пересобрать со сверкой»** (`rebuild`). Ждущий черновик получает `superseded` тем же захватом state+ver, новый
   проход Т4а даёт новый черновик со своей карточкой; второе нажатие — «уже решено». При флаге вкл. черновик без
   строки `attach` на «Отправить» снимается `stale`.
6. **Слова рукам:** «текст: ушёл · PDF: ушёл / не ушёл: причина / неизвестно» (`parts_words`), одной правкой
   карточки после обеих частей. **Журнал** `part_log` и `self.log`: кто, когда, часть, попытка, исход, wamid,
   sha256. Номера и тексты в журнал не пишутся (тест с приманкой).
7. **Флаг выкл.** `AttachCore(attach=False)` и `make_core({})` повторяют `Core`: голден сравнивает ответ нажатия,
   строки `drafts`, карточки, вызовы двери, журнал и набор таблиц (новых таблиц нет).
