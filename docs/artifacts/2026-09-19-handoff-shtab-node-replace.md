## Мина адреса: имени `KB_handoff_shtab` в реестре Brain НЕТ

`brain_writer.py --name KB_handoff_shtab --probe` отказывает дословно: «ИМЯ НЕ РАЗРЕШЕНО:
'KB_handoff_shtab' → канон 'handoff_shtab'. В живом реестре такого ключа нет (ключей 38)».
Замер 19.09: `list_brain` → 38 ключей, `handoff_shtab` среди них нет; `list_folder` → в папке
Brain **328** детей, и файл `KB_handoff_shtab` там есть. То есть узел живёт в папке БЕЗ ключа
реестра — ровно тот класс, ради которого заведён `list_folder` (реестр ≠ содержимое папки).

Два готовых ложных диагноза:
- «узла нет, мост его не знает» — узел жив, спрошен в чужом словаре (класс разрешения имён).
- «ну значит это `handover`» — **другой узел**: `KB_HANDOVER`, 48336 символов, собран 15.08.2026,
  заголовок «ПЕРЕДАЧА В НОВЫЙ ЧАТ». Слепок Штаба туда писать было бы записью не в тот док.

Отсюда и адресация записи: по `--id`/`doc_id`, а не по имени.

## Честный остаток: хвост текста пришёл обрезанным

Текст для записи в теле задачи обрывается на полуслове — последняя строка узла кончается
словами «…Кто его пишет после 09». Это обрезка транспорта задания (тело задачи режется с
хвоста), а не авторский текст Штаба. Записано **дословно**, как велено; отсебятина не
добавлялась и метка в узел не ставилась. Недостающие строки дописываются вручную — либо
следующим слепком, либо `brain_writer` с якорем на эту строку.
