## 1. Форма пометки

```python
head = text[:120]        # рез: показ
key = sha[:12]           # рез: решение — ключ: первые 12 hex sha256, коллизия не страшна
# рез: показ
line = one_line(why, 50)
```

- **Место:** любая физическая строка выражения реза или строка-комментарий прямо над ним. Комментарий над строкой кода с собственной пометкой соседний рез не покрывает (замок `test_marker_on_a_code_line_above_does_not_cover`).
- **Машинное чтение:** `#\s*рез:\s*(показ|решение)(.*)$` через `tokenize`. Новый файл не нужен.
- **`показ`** — рез живёт только на пути к человеку.
- **`решение`** обязано назвать право (якорь формата, ключ, машинный знак на своём месте) не короче 3 знаков. Голое `# рез: решение` — это объявленное нарушение правила, и сторож его красит (`решение без права`). Так пометка несёт доказательство, а не только ярлык.

## 2. Сторож

`cut_mark_scan.py`. Резом считаются четыре формы:

| подпись | форма | не считается |
|---|---|---|
| `head` | `x[:B]`, B не отрицательное число | `x[:-3]` (снятие известного хвоста), `x[1:]`, `x[2:5]`, `x[::2]` |
| `tail` | `x[-B:]` | `x[i]` |
| `helper` | вызов функции реза полосы: `one_line`, `_tail`, `_tail_shown`, `_last_line`, `first_line`, `_cap_result`, `_clip*`, `clip_named`, `shown`, `goal_line`, `_cut_head`, `cut_head`, `shorten` (список снят по определениям 17.09; `short`/`_short`/`_cut` не взяты — у полосы это голова sha) | — |
| `bytes` | `f.read(N)`, `f.seek(-N, …)` | `f.read()` |

- **Область:** отслеживаемые git `*.py` корня, без `test_*`, `tmp*`, `_scratch*` — 140 файлов. `suggest.py` в области: клиентский контур — родина мест №24–27.
- **Известные:** `cut_mark_known.json` — ключ `подпись|выражение` с кратностью по файлу, без номеров строк. Сдвиг кода сторожа не будит. Правка выражения известного реза или такой же рез сверх кратности — будит: тронул рез — пометь.
- **Список только убывает:** дата `2026-09-17` и потолок 755 прибиты в `test_cut_mark_scan`. Строка «устарело в списке N» печатается, но не краснеет.
- **Слепота громкая:** нечитаемый файл даёт rc=2 и «НЕ СЧИТАНЫ (это НЕ «чисто»)», а не ноль.
- **Коды:** 0 — нарушений нет, 1 — новый рез без годной пометки, 2 — файл не прочитан.
- **Режимы:** дерево; `--files`; `--staged` (содержимое индекса через `git show :путь`, для хука); `--list`; `--json --measured` (перепись); `--root`/`--known` (стенды).

**Предел метода, назван вслух:** рез по разделителю без числа (`split(sep)[0]`, `splitlines()[-1]`, `partition`) сторож не видит, если он не завёрнут в функцию из списка. Не видит и рез вне Python (мост `slice(0,5000)`) или вне формы (`max_tokens`, «файл > 2 МБ → пусто»).

Строка для хука, с той же полярностью, что у соседа: rc=1 держит коммит, прочее пропускает громко.
```
"$py" "$repo/cut_mark_scan.py" --staged; rc=$?; [ "$rc" = "1" ] && exit 1
```

**Не подключено этим заходом, сознательно.** Хук исполняют все заходы, включая соседний, идущий сейчас. Включение меняет поведение чужого коммита посреди его работы, поэтому это решение владельца или Штаба, а не мой побочный шаг. Правка — одна строка в `deploy/hooks/pre-commit`.

**Почему не гейт.** Селективный гейт берёт `test_<stem>` изменённого файла (`gate_selective.affected_test_modules`, `pc_orchestrator._affected_test_modules`).
