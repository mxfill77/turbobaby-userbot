- Дословный вывод каждой команды + полный гейт + суточный реплей

7. ДОКТРИНА ПОДТВЕРЖДЕНИЙ:
- Судить по ДЕЙСТВИЮ, а не по совпадению слов.
- ДВА ВИДА КАРТОЧКИ. Высший — живые таблицы, деньги, клиентский
  контур, выкатка прода, удаление вне tmp, снос процессов — нужен
  ответ с объектом; без названного объекта не выписывается вовсе.
- Нет числа или имени в карточке — она не должна была появиться.
- ОДНА КАРТОЧКА — ОДНА ОПЕРАЦИЯ. Склейка = отказ.
- ОБЪЕКТ КАРТОЧКИ = ЦЕЛЬ операции, а не имя функции.
- Карточку рождает только маркер гарда со сверкой токена.
- ПЕРЕЗАПУСК ЖИВОГО ПРОЦЕССА — отдельное разрешение.
- Карточка не устаревает сама.
- Отказ владельца ТЕРМИНАЛЕН. bypassPermissions не включаем.

8. ПРАВИЛА ШТАБА: KB_MASTER — точка входа №1. Задачи — в блоке
кода. Никогда не объявлять завершение по слову агента. Досыл
к задаче = новая задача. Перед повтором упавшей — сначала статус
очереди. Не предлагать паузы. Рамка — рабочий инструмент, не
архив: закрытое снимать, изменчивое выносить в мозг. Шаг за
шагом: один заход — одна цель.

8в. ЭКОНОМИЯ КРУГОВ:
- ВТОРОЙ СЛУЧАЙ КЛАССА = разведка списком, не третья заплата.
- ФИКС НЕ ИДЁТ В СРЕДУ, ЧЕЙ ДЕФЕКТ ОН ЧИНИТ.
- КООРДИНАТЫ ТОЛЬКО СВОЕЙ ПОЛОСЫ: Штаб называет симптом и живой
  факт, место исполнитель находит сам.
- СТАНДАРТНЫЙ БЛОК ЗАПРЕТОВ В КАЖДОМ ТЗ: ничего не удалять,
  включая уборку за собой; место для временного назвать явно;
  в разведке пробных скриптов не запускать; .env и конфиги
  не читать — читать код, который их читает; боевых записей нет;
  процессы не трогать без отдельного разрешения.
- ДОГАДКА ШТАБА ПРОВЕРЯЕТСЯ ДО ТЗ.
- МЕТРИКА ПРОГРЕССА — число карточек, НЕ дошедших до владельца,
  и число цепочек, пройденных дирижёром без вмешательства
  владельца.
- КРИТЕРИЙ ВЫХОДА ИЗ ФАЗЫ обязателен ДО начала фазы. Фаза
  фундамента закрыта, когда сутки обычной работы проходят без
  ложной карточки владельцу. Ложная = карточка, за которой нет
  настоящей операции. Нет критерия — фаза не кончается никогда.
- ЧЕРЕДОВАНИЕ. Закрыт класс — Штаб смотрит, есть ли бизнес-висяк,
  который ждёт дольше этого класса. Ждёт — следующий заход туда.
  Инженерная чистота, за которой месяц не двигается бизнес, —
  это дебри, а не фундамент.
- ПОЛОВИНА НАХОДОК РОЖДЕНА НАШИМИ ЖЕ ЗАХОДАМИ. Считая метрику
  карточек, отделять карточки от обычной работы от карточек,
  рождённых задачами по самому гарду.
