## 7. ЧТО ВСЁ-ТАКИ ЧИНИТЬ: `send_note` считает провал успехом

Единственный дефект, найденный в цепи. **В этом случае он НЕ сработал** (журнал говорит `ok=True`),
но он лежит ровно на пути каждой заметки ожиданий.

`expectations_pc_run.py:1142`:

```python
return bool(dispatch_notify.deliver(text))
```

`deliver()` возвращает **ПАРУ** `(channel, ok)` — так объявлено в его докстроке
(`dispatch_notify.py:555`) и так его читают **все шесть** остальных вызовов в репозитории
(`channel, ok = deliver(...)` — `dispatch_notify.py:921,946,957,974,1007,1021`).
`expectations_pc_run.py:1142` — **единственное место, берущее `bool()` от пары.**
Непустой кортеж истинен всегда:

| что вернул `deliver()` | ok | `bool(...)` |
|---|---|---|
| `("none", False)` — нет токена бота | False | **True ← ложный успех** |
| `("inbox", True)` — ушло в 1160 | True | True |
| `("DM", True)` — фолбэк в личку | True | True |
| `("DM", False)` — легли ОБА канала | False | **True ← ложный успех** |
| `("none", False)` — нет токена (тема) | False | **True ← ложный успех** |
| `("topic:328", True)` | True | True |

**3 ветки из 6 — ложный успех.** Что это стоит владельцу: в `run()` замысел записан прямо в коде
комментарием — `if not send(...): continue  # не помечаем — скажем на следующем прогоне`.
Эта ветка **недостижима**: `send_note` отдаёт `False` только при исключении. Значит при лежащем
канале эпизод помечается сказанным, хотя владелец не получил ничего, и дальше:

* **О1–О6** — `if was is not None: continue`, заметка **не повторится никогда**;
* **О7** — молчание до пола повтора, то есть **сутки**.

Правка (НЕ сделана — задание запретило): `channel, ok = dispatch_notify.deliver(text); return bool(ok)`.
Доказательство — `tmp/o7_probe_0906/send_note_bool.py` (чистая арифметика, ничего не отправляет).
