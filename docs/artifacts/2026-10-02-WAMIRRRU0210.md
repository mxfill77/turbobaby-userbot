## 2. revoke — удаление с телефона

`wa_tg_mirror._revoke_one` (`:908`), своя ветка живой ленты (`_advance`, `:846`), раньше `_show_one`:

1. Цель — `revoke.original_message_id` из `raw` строки (`_revoke_target`, `:865`; читается так же, как
   `_react_fields` читает реакцию).
2. **Цель показана одна и её id есть** (`_target_where`, `:852`: ключ `msg:` или `file:` цели, `state=shown`,
   `solo=1`, `msg_id` не пуст) — правка этого сообщения темы:
   - текст — `editMessageText`, файл (живой файл или файл хвоста) — `editMessageCaption`;
   - новый текст = прежний + «\n🗑 удалено с телефона ЧЧ:ММ» (время удаления, Пхукет); прежний — зачёркнут
     (`strikethrough`, длина в единицах UTF-16 — эмодзи считаются как в Telegram);
   - прежний текст восстанавливается теми же функциями, что его показали (`_shown_body`, `:897`): живая лента —
     `_live_view` (показ живой строки вынесен из `_show_one` в неё, `:1030`), хвост предыстории — `item_line`,
     файл хвоста — подпись «дата кто». Тест сверяет правку с ДОСЛОВНО отправленным текстом.
3. **Иначе — одна строка** «ДД.ММ ЧЧ:ММ мы: 🗑 удалено сообщение от ЧЧ:ММ». Случаи: цель в пачке
   (правка задела бы соседние строки), показана до хранения id, не показана, не из этой темы, правку чат не
   принял (400). Время цели берётся из очереди, иначе из архива номера по key_id (`_target_ts`, `:878`).
   Другой день — «от ДД.ММ ЧЧ:ММ»; цели нет нигде — «🗑 удалено сообщение — какое, неизвестно». Когда цель
   показана хоть в пачке — строка идёт ответом на неё (`reply_parameters`).
4. **Повтор.** Ключ строки — как у всех (`msg:<wamid>`). Плюс ключ цели `rev:<wamid цели>`: такт, рестарт,
   тот же wamid и второй revoke той же цели правки и строки не повторяют. Нет ответа на правку — «не уверен»,
   повтора нет (как `_deliver`). Отказ не 400 — повтор следующим тактом.

**Почему прежний текст оставлен (зачёркнутым), а не стёрт.** Тема — рабочая запись бизнеса, а не зеркало
телефона. Сотруднику важно, ЧТО удалено: неверная цена, адрес, номер брони. Стирание ничего не прячет —
текст остаётся в очереди, в архиве и в файле истории, — но отнимает у сотрудника контекст. Зачёркивание
и пометка не дают принять удалённое за действующее.

В истории (файл, хвост, модель) строка revoke — словом «[сообщение удалено с телефона]».

## 3. unsupported и прочие виды без текста — русским словом

`wa_history.KIND_WORD` (`:49`):

| вид | слово |
|---|---|
| `unsupported` | неподдерживаемое сообщение — смотреть в телефоне |
| `revoke` | сообщение удалено с телефона |
| `edit` | сообщение изменено |
| `errors` | сообщение не передано — смотреть в телефоне |
| `contacts`, `contact` | контакт |
| `location`, `live_location` | геоточка |
| `interactive`, `button` | ответ кнопкой |
| `order` | заказ из каталога |
| `system` | служебное сообщение |
| `text` (пустой) | пустое сообщение |
| `reaction` · `status` · `deleted` · `waiting` | реакция · квитанция · удалено · ожидает |
| **вне словаря** (`code_99`, новый вид Meta, пустой тип) | **сообщение неизвестного вида** (`UNKNOWN_WORD`) |
| медиа вида вне словаря (архив `code_25` с файлом) | **файл** — «[файл — на сервере / файла нет]» |

- **Одно место на три дороги:** `body_of` (тема), `queue_item`/`arch_item` → `item_line` (файл истории и хвост) и
  `model_line` (модель) зовут одну `kind_word`.
- **Строка журнала с именем вида:** `kind_word` кладёт имя неизвестного вида в `unknown` (параметр `merge`,
  `queue_item`, `arch_item`). Служба пишет по нему `note_unknown`: WARNING «показ: вид сообщения code_99
  неизвестен — показан словом «сообщение неизвестного вида»», одна строка на вид за жизнь процесса. Имя — только
  формы `[A-Za-z][A-Za-z0-9_.-]{0,39}`, иначе «<не имя вида, N симв.>»: текст или номер клиента в журнал не попадут.
  `wa_history` по-прежнему без журнала и с теми же импортами.
- **Сторона неопознанного вида — по `echo`.** `unsupported` от клиента (echo 0, history 0) по `wa_kind` — `unknown`,
  и раньше шёл как «?: [unsupported]». Теперь `who_of` даёт «клиент»/«мы» по записанному echo. echo не записан — «?».
- Строку «[медиа — файл Meta не отдаёт]» и «… больше лимита Telegram» не трогал: латиница там — имена служб,
  а не вид. Тест (4) их так и различает.
