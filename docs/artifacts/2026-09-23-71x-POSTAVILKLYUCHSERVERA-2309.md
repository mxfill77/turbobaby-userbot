## Попутная находка (для Штаба): гард этот запуск не держит

`vps_token_install.py --probe-slots` загружает секретный файл сервера в оболочку, и собственная
шапка инструмента называет режим «класс `env`, запускает владелец». Гард ПК при этом пропустил
его **без карточки**. Скрипт отслеживается git, а для таких тело не сканируется: доверие по
происхождению, `pretool_guard._scan_python` → ветка `_is_repo_tracked`. Удалённая команда при
этом — `bash -s` без имени секрета в argv. Значит, headless-заход удерживает от этого чтения
только блок запретов задания. Гард его не удерживает. В этот раз чтение было разрешено словом
владельца. Правка гарда в этом заходе не делалась.
