## 4. Замок по существу (пункт 4): что именно сделано

Правлен **РОВНО ОДИН боевой файл** — `exam_show.py` — плюс его набор `test_exam_show.py`.

**(а) Свой файл убран из сравнения по времени.**
`BUTTON_CLOSURE = ("pc_agent.py", "exam_show.py")` → `BUTTON_CLOSURE = ("pc_agent.py",)`.
Сравнение по времени теперь ведётся только с тем файлом, который **живёт в памяти процесса**.

**(б) Расхождение кнопок ловится СОДЕРЖИМЫМ.** Добавлены две функции:

- `card_callbacks(case_id, shot)` — все `callback_data`, которые НАПЕЧАТАЕТ карточка этого
  снимка. Источник один с отправкой — `markup`; второй перечень литералами разъехался бы с
  печатью молча, и замок зеленел бы на кнопках, которых в карточке уже нет.
- `agent_parse(src_path, read_fn)` — разбор `exam:` живого агента, вынутый из его исходника
  **ТЕКСТОМ, а не импортом** (`import pc_agent` затащил бы сюда живого бота с его конфигом, а
  нужна ровно одна строка `EXAM_CB_RE`). Не нашёлся — исход НЕИЗВЕСТНО, а не разрешение:
  исчезнувший `EXAM_CB_RE` значит «разбор переехал», а переехавший разбор мы не знаем.

**(в) `pc_agent.py` ОСТАВЛЕН в сравнении по времени, и порядок проверок жёсткий.** Это не
перестраховка, а **условие законности** сверки содержимым: разбор мы читаем **с диска**, а
разбирает тап код **в памяти процесса**. Равны они только пока файл старше рождения процесса.
Поэтому сперва время `pc_agent.py`, и лишь потом содержимое — иначе сверка пошла бы с кодом,
которого в процессе нет.

**(г) Префикс, которого разбор не принимает, даёт ОТКАЗ показа** — это отдельная ветка `False` со
своими словами, не смешанная с временной: «разбор живого агента (pid N) НЕ принимает K из M
колбэков карточки: …; его разбор — «…»; тап по такой кнопке агент сочтёт чужим и МОЛЧА не
донесёт до двери».

**(д) Показ отдаёт замку колбэки ЖИВОГО снимка**, а не литералы: `show()` зовёт
`agent_carries_button(callbacks=card_callbacks(case_id, shot))`. Предмет сверки задают ДАННЫЕ —
число подсказок снимка решает, какие `exam:hN:` выйдут наружу. Проба `--agent` повторяет живой
путь: без `--case` карточки нет, и замок честно отвечает НЕИЗВЕСТНО, а не «ДА».

Три исхода сохранены, и третий по-прежнему запрещает показ. Их теперь четыре повода: нет лока ·
нет момента старта · **карточка не предъявлена** · разбор из файла исчез.
