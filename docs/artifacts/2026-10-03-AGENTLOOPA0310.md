## Контракт инструментов (`wa_agent_tools.py`)

Ответ каждого инструмента: `tool · outcome · source · ref · at (время чтения) · version · window · reason · facts`.
Исходы: `fact`, `empty`, `refused`, `timeout`, `cancelled`, `ambiguous`, `unknown`, `incomplete`. **Фактом считается
только `fact`**; остальное идёт в журнал отказов, суждения на нём не строятся.

| инструмент | дверь | факт | не факт |
|---|---|---|---|
| `history` | адаптер: `wa_history.read_history` (очередь + архив WA) | число строк, суммы в батах из переписки | история не прочитана · пусто |
| `rental` | адаптер: снимок броней, активные по последним 9 цифрам номера | одна аренда: booking_id, байк, срок, статус, цена (если есть в листе) | брони выкл · не найдено («не знаю», а не «нет») · несколько (`ambiguous`) · отменены |
| `cash` | `bridge_client.tx_find` (GET) | строка с `row`, `msg_id` или `link`, временем, связью с арендой (booking_id или байк + срок), суммой-числом, валютой и ролью по `category` | `checked.complete` не True (у 83ee219 поля нет — «до TXFINDFIX»), обрезка — `incomplete`, суммы и даты «не проверено» · строка без источника/связи/суммы · `void` — `cancelled` · `unknown_action` — `unknown` |
| `contract` | `contract_find` (GET) | `outcome=one` и `signed=True`: строка, doc_id, байк, дата договора, дата подписи, pdf_id | `ambiguous` · `none`/`none_signed` — `empty` · прочее — `unknown` |
| `contract_pdf` | `contract_pdf` (GET) | только метаданные: id, имя, размер, sha256, строка; `content_b64` отбрасывается | не в реестре, не подписан (`refused` с причиной двери) · `verified` не True |
| `delivery` | двери нет | — | всегда `unknown` «двери delivery нет» |
| `rules` | адаптер: снимок узла `business_rules` | длина, есть ли запись 03.10.2026-1 | узел не прочитан |

Общий `total` кассы код не читает вовсе. Роли по `category` (у splinter: `rental|salary|advance|fuel|taxi|topup|other`,
отдельной категории залога нет): сумма > 0 и слова «залог/депозит» — залог; `rental` и сумма > 0 — оплата аренды; сумма < 0
с `rental` или словами возврата — возврат; прочее — не деньги клиента.

**Цикл.** Модель отвечает JSON: `{"tool": имя, "args": {…}}` или итоговым черновиком прежней формы. Предел — **8 вызовов
модели и 90 с** на черновик. Превышение → обычный черновик одним вызовом (тот же, что без флага), факты сверки не
опора, причина «сверка не завершена» первой. Новое входящее посреди сверки (`fresh` = `core._fresh`) → черновика нет,
служба повторит позже.

**Как ожидание держит других клиентов — честно.** `wa_agent.Core.make_drafts` делает черновики по одному за такт. Значит
сверка одного клиента держит остальных до 90 с плюс один обычный вызов при превышении; при N клиентах в очереди — до N
таких отрезков. Параллели в этом заходе нет. Это предел, а не решение.

**Код считает и судит** (`judge`): суммы по ролям и валютам и разность «цена аренды минус оплата» — только из принятых
строк кассы. Опора денежной проверки = «ЦЕНА» ∪ факты ∪ расчёты; сумма в батах и **число без валюты в предложении с денежным
словом** судятся («PCX 160», дни, км, проценты — нет). Причины: «оплата не подтверждена сверкой» — текст подтверждает
оплату без строки оплаты аренды и второго источника (подписанный договор либо аренда из листа плюс та же сумма в
переписке; лист сам по себе договором не считается); «денежная роль не сходится с кассой» — залог без строки залога,
«вернём» при записанном возврате, сдача без «в конце, с возвратом залога» («сдача байка» деньгами не считается); «суммы
расходятся» — разность не ноль или байк аренды и договора разный. Текст черновика код не правит, причина идёт первой.

**Журнал на черновик** (`self.log`, строки `сверка …NNNN:`): каждый вызов — номер, имя, вход без персональных данных
(телефон — последние 4 цифры, имя — «[имя]»), источник, время, итог и причина; принятые факты (row, msg_id, link, время,
booking_id, роль, сумма, валюта / подпись договора / метаданные PDF); конфликты; отказы. Текста модели и её рассуждений в
журнале нет — тест держит это приманкой.

**Флаг выключен = 9c4aac6.** `ModelAdapter(tools=None)` идёт прежним путём без изменений. Голден: 4 ответа модели (цена,
деньги, чужой язык, не JSON) через адаптер дерева `9c4aac6` (загружен `git show`) и ветки — ответ и журнал равны. На ПК

НЕ зелёное» и считается зелёным — это недостаток счёта теста). `main()` при выключенном флаге зовёт `make_model` той же
