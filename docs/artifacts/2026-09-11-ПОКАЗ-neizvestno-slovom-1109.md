## 2. Правка: два показа, один исход

Оба показа теперь отвечают одинаково: **источник не прочитан или старше названного предела → незнание
говорится, а не заменяется нулём.**

### Место 1 — журнальная сводка (`contour_digest.py`)

```
journal_line:1039   def shown(key):
                        return counted.get(key, 0) if counted else "?"
                    …· серия %s/%s (доказал судья %s · без адреса %s · меняли состояние %s · %s)
unknown_words:909   unknown = got.get("unknown", 0) if got else "?"
                    window  = got.get("window", 0)  if got else "?"
                    words = "НЕИЗВЕСТНО %s из %s" % (unknown, window)
```

Знак взят у соседнего поля (П3), а не выдуман новым видом: два показа одной величины расходятся молча —
класс полосы, и лечить его новым видом незнания значило бы завести третий. `target` остаётся числом
намеренно: 30 — это КРИТЕРИЙ фазы, он известен без всякого источника, и прятать его было бы враньём в
другую сторону.

`unknown_words` правится, а не обходится, по той же причине: слово «НЕИЗВЕСТНО» обязано иметь **одну
дверь**. Второй литерал в `journal_line` развёл бы формулировки при первой же правке. Проверено, что
изменение никого не задело: у `series_line` ветка с пустым счётом недостижима (строка с `kind=UNKNOWN`
возвращается раньше), у `vitrina_pc.part_nums` вызов стои́т только в ветке живого счёта.

### Место 2 — сбор витрины (`vitrina_pc_run.py`)

```
collect:620   fresh = cdr.fresh_or_none(snapshot, q_at, now, "queue")
              if fresh is not None:
                  counted = cd.series(cdr.all_closed(fresh), judged=cdr.read_judged(root))
```

Предел берётся **там, где уже назван** — через дверь сводки `contour_digest_run.fresh_or_none`, которая
сама спрашивает `cd.limit_of(src)`. Числа `3600` в витрине не появилось: второй экземпляр предела
развёл бы два показа ровно так же, как их развело правило показа. Третий исход сохранён — возраст не
сверить → `None` ведёт в «неизвестно», а не в «свежо» (это свойство самой `fresh_or_none`).

Печать витрины правки не потребовала вовсе: `vitrina_pc.part_nums:785` уже умела говорить словом через
`number(None, …)` — не хватало ровно того, чтобы `counted` до неё доезжал пустым.
