## 2. Номера двух баз не смешиваются — в обе стороны

Ключи названы по базе: `--from-set N` — номер набора, `--rollback M` — номер базы бота. «Номера вообще»
нет ни в одном ключе.

| направление | опыт | исход |
|---|---|---|
| набор → база | перенос урока набора #2, в базе #2 занят чужим уроком | в тесте урок сел на новый номер, сырые байты строки #2 базы не изменились, отпечаток набора не изменился. На копии: урок набора #12 → урок бота #10, одноимённый #12 базы не тронут, копия набора равна боевой по отпечатку |
| база → набор | откат переноса по номеру базы #4 (в наборе тоже есть #4); на копии — по #10 | строка #4 (#10) набора и весь набор не тронуты |
| номер базы, который из набора не переносился | откат переноса урока бота #2 (тест) и #12 (копия, урок книги) | отказ словами, база не тронута |

Тесты: `test_set_number_does_not_touch_the_same_number_in_the_base`,
`test_base_number_does_not_touch_the_same_number_in_the_set`.

## 3. Откат по номеру — байт в байт

Откат переноса (`--rollback M`) возвращает файл базы к байтам до переноса. Он проходит только если база
с момента переноса не изменилась ни байтом: размер и отпечаток всего файла сверяются с записью о
переносе, а отпечаток префикса — с отпечатком «до». Иначе отказ, и ничего не тронуто. Режет та же
дисциплина, что у `lesson_store._rewrite`: копия `.bak` до правки, новое тело во временном файле,
атомарный `os.replace`, подъём версии по факту.

| шаг (копия `tmp/most_urokov/copy/lesson_store.tsv`) | отпечаток базы |
|---|---|
| до переноса | `7d19b1db352e8f76…` (= боевая база) |
| после переноса урока набора #12 → бот #10 | `ca00d690e367be0e…` |
| после отката #10 | **`7d19b1db352e8f76…`** — первая = третья |
| второй откат | «перенос уже откачен», отказ |

То же на тестовой базе: `test_before_after_rollback_first_equals_third` (sha1 ≠ sha2, sha1 = sha3,
`version().ok`). База изменилась после переноса — отказ «изменилась», байты не тронуты
(`test_rollback_refuses_when_the_base_moved…`). Кандидат переведён после переноса — откат переноса
отказывает, пока не откачен перевод; после «урок откати M» откат переноса проходит, база = до
(`test_promoted_candidate_rolls_back_in_two_steps`).

**Урок без записи о переносе откатить нельзя, и дверь говорит это словами** (копия, урок бота #12):
«⛔ откат переноса НЕ сделан: урок бота #12 из набора не переносился — записи о переносе нет.
Откатывать нечего. Убрать действующий урок можно снятием («отмени урок 12») — это новое состояние, а не
возврат байтов».

## 4. Ложь показа закрыта: слова — только после живого читателя

**Живой читатель** — ровно тот вызов, которым собирается ответ:
`suggest.make_system_prompt(…, playbook=suggest.load_playbook())`. Адрес базы ему не передаётся, он
читает свой: `suggest.LESSON_BASE_PATH`, а при `None` — `lesson_store.STORE_PATH`. **Мерило** — число
строк собранного промпта, равных буллету урока (`suggest._lesson_bullet`), до записи и после. Вошёл
только при «после = до + 1». Такой же текст, уже стоявший в промпте из книги, вхождением не считается
(тест: до 1, после 1 → отказ).

| исход | карточка | код |
|---|---|---|
| читатель вернул строку | «✅ … ВОШЁЛ В ОТВЕТ: живой читатель вернул строку урока в собранном промпте (было N, стало N+1) — бот отвечает по нему со следующего ответа» | 0 |
| причины нет | «📝 … записан КАНДИДАТОМ … в ответ он НЕ входит и бот по нему не отвечает. Включить — …» (базе бота диктуется слово темы, копии — консольная строка с `--path`: слово без `--path` ударило бы в одноимённый номер боевой базы) | 0 |
| записан, читатель не вернул; сверить не удалось | «⛔ Перенос НЕ состоялся как правило: … записан … но в ответ ещё НЕ вошёл — …; читатель читает <адрес>[, чтение ВЫКЛЮЧЕНО]» | **3** |

**Дверь перевода `lesson_promote.py`** получила тот же замок. Замер до перевода — по буллету кандидата:
перевод меняет только «почему» и состояние, а буллет собирается из «как правильно» и «когда». Если
читатель строку не вернул, первая строка карточки `trainer._promote_lesson` («ВКЛЮЧЁН — бот отвечает…»)

откат остаются, код 3. Замок формы: тест краснеет, если обещание уедет из первой строки карточки. Сам

## Честные границы устройства

- **Запись о переносе ложится после строки:** ей нужны отпечатки «после». Если процесс оборвётся между
  ними, строка останется без записи, и откатить её переносом будет нельзя, только снятием.
- **Откат освобождает номер:** следующая запись в базу может получить тот же номер. Байты не спутаются
  (запись хранит отпечатки), но номер в истории станет неоднозначным.
- **Режим перенесённой строки — «неизвестен»:** источник `экзамен` двусмыслен (`lesson_store.SOURCE_MODE`).
  Читатель по режиму не фильтрует, поэтому на ответ это не влияет.
