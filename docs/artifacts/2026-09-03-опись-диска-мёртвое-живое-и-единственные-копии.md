## 4. Странности: имена, рождённые ошибкой пути

### 4.1 Каталог «D:\turbobaby-bot» ВНУТРИ D:\turbobaby-bot

**Что это по-настоящему.** Имя на диске — не текст `D:\turbobaby-bot`, а последовательность
`D` + **U+F03A** + **U+F05C** + `turbobaby-bot` (коды 68, 61498, 61532, …). U+F03A и U+F05C — это
MSYS/Cygwin-кодировка символов `:` и `\`, которые Windows в имени файла запрещает. То есть на диске
лежит буквально имя `D:\turbobaby-bot`, записанное единственным способом, каким Windows это
позволяет.

**Мина при проверке.** Из Git Bash `ls 'D:\turbobaby-bot'` показывает НЕ этот каталог, а настоящий
корень: MSYS переводит `D:\...` в `/d/...` раньше, чем доходит до имени. `find 'D:turbobaby-bot'`
честно отвечает «No such file or directory». Каталог виден только из PowerShell по кодам символов —
чем он здесь и вскрыт. Заодно `Get-ChildItem | Where-Object { $_.Name -match '[:\\]' }` даёт **ноль
совпадений**: обычный `:` в имени и правда не встречается.

**Что внутри — целиком.**

| тип | размер | mtime | путь внутри |
|---|---:|---|---|
| каталог | — | 01.09.2026 11:41:01 | `tmp` |
| каталог | — | 01.09.2026 11:41:01 | `tmp\deadprem-selftest` |
| файл | **34 байта** | 01.09.2026 11:41:01 | `tmp\deadprem-selftest\probe_body.py` |

Содержимое файла целиком — две строки: `import os` и `os.remove('victim.txt')`. Это **тело
самопробы гарда** на класс «удаление файла».

**Откуда взялся по датам.** Создан и записан **01.09.2026 в 11:41:01**; ctime, mtime каталогов и
mtime файла совпадают до секунды, и с тех пор **не менялся ни разу** (замер 03.09). Значит это один
заход, одна операция записи, и никакой процесс с ним больше не работал. Механизм: заход самопроверки
гарда склеил абсолютный `D:\turbobaby-bot` с относительным `tmp/deadprem-selftest` и отдал результат
POSIX-слою, для которого `D:\turbobaby-bot` — не путь, а имя каталога; слой честно создал каталог с
таким именем, экранировав запрещённые символы. Что это именно самопроба, а не что-то боевое,
подтверждает сосед: рядом в настоящем `tmp/` живёт `deadprem-20260802-q7` — тот же класс пробы,
легший по правильному адресу 02.08.

**Есть ли внутри что-то, чего нет больше нигде.** По имени — да: `probe_body.py` встречается на всём
диске **ровно один раз**, и это он. По смыслу — **нет**: две строки восстанавливаются повтором
захода за секунды. Ценность содержимого нулевая; ценность самого каталога — в том, что он
**вещественная улика класса «путь Windows ушёл в POSIX-слой»**, и пока он лежит, класс доказуем.

### 4.2 Вторая странность — файл с приставкой каталога
