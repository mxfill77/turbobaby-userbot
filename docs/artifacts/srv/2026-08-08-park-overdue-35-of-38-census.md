**Что происходит с пустой клеткой — `splinter.py:4663-4671`:**


Прямой ответ: **есть третий исход, но он третий только на словах, а в СЧЁТЕ ведёт себя как ноль.**
Пустая клетка помечается `nobase=True` и рисуется отдельной фразой «❗ не делалось»
(`_o3_card_render`, splinter.py:4696), но кладётся в ТОТ ЖЕ список `items`, а байк — в тот же
`overdue`, который и посчитан как 35. Единственное смягчение против чистого нуля — порог
`cur >= interval`: пока пробег не дорос до 10000 (ABS) / 20000 (фильтр), байк не показывают.
Именно этот порог, а не «не измерено», удержал 2 клетки K и 8 клеток L (см. §5).

**Ниже по стеку различать уже нечего** — `ReadFleet.js:452-459`:

```javascript
function parseNumber(val) {
  if (val === null || val === undefined || val === '') return 0;
  if (typeof val === 'number') return val;
  // Убираем валюту, пробелы, неразрывные пробелы
  const cleaned = String(val).replace(/[฿$\s ,]/g, '').replace(',', '.');
  const n = parseFloat(cleaned);
  return isNaN(n) ? 0 : n;
}
```

Пустая клетка, прочерк «-», любой нечисловой текст и настоящий ноль приезжают в Python
**одним и тем же `0`**. То есть «пустая клетка = не измерено» сегодня не может быть выражена
в принципе: различие уничтожено на стороне моста, до всякой логики скана. Отсюда же следует,
что признак `nobase` восстановлен из `last <= 0`, а не из знания, что клетка пуста.

Отдельно: интервалы прочитаны из книги знаний (не фоллбэк) и равны гипотезе штаба —
`abs: 10000`, `airfilter: 20000`, `oil` 4000/5000, `gear` 4000/None.


**Пересечения названы явно: сумма по видам 5+12+32+23 = 72 больше целого 35, и это нормально** —
один байк просрочен по нескольким видам сразу (7 байков по одному виду, 20 по двум, 7 по трём,
1 по четырём; 7·1+20·2+7·3+1·4 = 72 сходится).

Из 35 попали в счёт **ТОЛЬКО из-за пустой клетки — 12 байков**; у остальных 23 есть хотя бы одна
просрочка по настоящему замеру. Пустая клетка не дала ни одной просрочки по маслу (столбец I
не пуст ни у одного из 38) и ни одной по редуктору (все 9 пустых J — у мотоциклов, где вид
не трекается вовсе).

## 3. Встречное число

**Если пустая клетка = «не измерено» и в счёт не идёт — остаётся 23 из 38** (было 35).
`35 − 12 = 23`. По видам остаётся: масло 5, редуктор 12, ABS 14, воздушный фильтр 3.

Оговорка, которая делает 23 **нижней границей, а не точным числом**: у 26 байков из 38 своего
одометра нет вовсе, и «текущий пробег» для них — фоллбэк `max(I,J,K,L)`, то есть показание
на момент давней замены (`_odo_current`, splinter.py:1953). Настоящий пробег таких байков
не меньше — значит по-настоящему просроченных может быть больше 23, но не меньше.
Своим одометром судимы только 12 байков.
