# `docs/artifacts/srv/` — артефакты СЕРВЕРНОЙ полосы, привезённые доставкой

Файлы этой папки **не написаны на ПК**. Их кладёт сюда `srv_delivery.py` (`extract_artifacts` —
новое из доставленных коммитов, `backfill_legacy` — добор того, что прошлые обороты успели
положить только во временный каталог). Заведена 03.09.2026, этап 3 доставки.

## Зачем папка вообще есть

До 03.09 приехавшие артефакты ложились в `tmp/srv_delivery/artifacts` — временный каталог
доставки. Замер того дня: серверная разведка `2026-09-03-server-contour-code-drift-recon.md`
лежала на ПК и **не читалась из `docs/artifacts` ни одной дорогой** (489 файлов в общей папке,
серверных среди них 0). Файл, которого человек не находит там, где он ищет артефакты,
доставленным не является — отсюда эта папка.

## Мина: канон этих файлов НЕ здесь

Канонический дом каждого файла — репозиторий серверной полосы
`turbobaby-manager-bot`, путь `docs/artifacts/<то же имя>`. Здесь лежит **копия для чтения**.
Отсюда три следствия, каждое — готовый ложный диагноз:

1. **Правка в этой папке никуда не уедет.** Доставка ходит в одну сторону (сервер → ПК) и на
   сервер не пишет ни одной командой. Правку нужно вносить на серверной полосе.
2. **Правку может затереть следующий оборот.** `extract_artifacts` перезаписывает файл, если тот
   входит в разрез очередной доставленной пачки. (`backfill_legacy` не перезаписывает никогда —
   он кладёт только то, чего в папке ещё нет.)
3. **`grep -rn` по `docs/artifacts` теперь смешивает ДВЕ полосы.** Совпадение в этой папке
   описывает VPS, а не ПК: «в артефактах написано X» без указания полосы — вывод класса
   born-false. Полосу видно по пути: `docs/artifacts/srv/` — сервер, `docs/artifacts/` — ПК.

## Чего здесь нет и не будет

Артефактов из веток, которых нет в общем репозитории (`backup-24-07`, `backup-main-2507`,
`wip-229-230`, `wip-works-buffer-50-56-20260822`). У ветки-новичка нет точки отсчёта: «что в ней
нового» неопределено, а вываливать её дерево целиком значило бы засыпать общую папку июльскими
копиями. Сохранность их содержимого держит push в общий репозиторий, а не эта выкладка.
