## Пульс НЕ тронут — почему

Задание велит при исходе ДОСТАВЛЕНО «обновить пульс на зелёный одной строкой», но его же
ЗАПРЕТЫ («читать первыми») прямо говорят «Только чтение», «в узлы мозга не писать»,
«мост … не трогать». KB_PULSE — узел мозга, запись в него идёт через мост, то есть нарушает
сразу два приоритетных запрета. Прямое противоречие двух директив разрешено в пользу запрета
(он помечен «читать первыми», а «Только чтение» повторено трижды); риск преждевременной записи
в мозг — ровно тот класс, которого этот контур избегает. Пульс оставлен жёлтым; вердикт
ДОСТАВЛЕНО назван. Готовая строка для владельца (или захода с правом записи), одна вставка
`write_doc(name=pulse)`:

```
2026-08-18 17:22 UTC | 🟢 | рестарт демона 14:55-доставки ПОДТВЕРЖДЁН: PID 1328816, старт 14:57:20 UTC, старт чистый (0 трассировок), оборот живой; открытых требований доставки 0 | ничего не жду | детали→docs/artifacts/2026-08-18-pulse-close.md
```

**FACT: read-only** — ни процессов, ни мозга, ни моста, ни гейта не трогал; изменений в
системе ноль. Единственная запись на диск — этот артефакт
`docs/artifacts/2026-08-18-pulse-close.md` (не коммичен: push погнал бы pre-push гейт, что
запрещено заходом). Живые улики исхода: MainPID=1328816, is-active=active/running,
ExecMainStartTimestamp=2026-08-18 14:57:20 UTC, старт-баннер `=== ДЕМОН СТАРТ … ===`.
