## п.6. Как Штабу дописывать сюда впредь (одной строкой)

Через ящик задание уходит полосе ПК. Полоса дописывает строки доверенным писателем
`brain_writer.append(строки, doc_id=<id из живого листинга по точному имени KB_owner_decisions>, anchor=r"^=== конец ящика ===$", place="before")`.
Это только добавление: гард усыхания, идемпотентность, бэкап и обратное чтение. Ручная замена
слепка целиком больше не нужна.

Оговорки к этой строке, честно:
- **По имени** (`--name KB_owner_decisions`) это заработает только после одной регистрации ключа:
  `brain_writer.py --register owner_decisions=<id>`. Канон имени подхватит её сам. Запись в реестр
  — отдельное решение, **здесь НЕ сделано**.
- Под капотом `write_doc` моста перезаписывает текст целиком. Семантику «только добавить»
  держит писатель.
- Проверен **файловый путь** (тело читается из файла скриптом). Однострочник CLI с кириллическим
  якорем в argv этой сессией не проверялся.
