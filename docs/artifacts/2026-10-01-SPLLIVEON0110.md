## 3. Как выключить бой и как откатить (ничего не удаляя)

**Выключить бой, код оставить** (путь станет равен 05efc4b на 40b158b, L5):
```
printf '[Service]\nEnvironment=TOPIC_DECIDER_LIVE=0\n' > /etc/systemd/system/splinter.service.d/live.conf
systemctl daemon-reload
systemctl restart splinter.service
```
Тень (`TOPIC_DECIDER_SHADOW`) при этом зависит от `.env`, а он не открывался. В бою тень молчит сама.
Паузы и вопросы решателя остаются в `decider_live_state.json`: файл никто не читает, пока флаг выключен.

**Откатить код** (живое дерево вернётся на 40b158b — WAREACTLIVE0110):
```
cd /root/turbobaby-manager-bot
git reset --keep 40b158b96450f0f09323258a87656731df964fd9
printf '[Service]\nEnvironment=TOPIC_DECIDER_LIVE=0\n' > /etc/systemd/system/splinter.service.d/live.conf
systemctl daemon-reload
systemctl restart splinter.service
```
Флаг без кода ничего не делает: в 40b158b имени `TOPIC_DECIDER_LIVE` нет. Значение 0 ставится, чтобы
следующая перемотка на код решателя не включила бой молча. События `decision` с `live` останутся в
`topic_feed/*.jsonl`, их читатель пропускает (SPLLIVEMODE0110 §7).

**Одну тему без отката** — пауза решателя по признаку (поправка реплаем или отклонённая кнопка) и
«Продолжить» в «Агентах» (SPLLIVEMODE0110 §4). Ручной паузы словом нет.
