## 3. Как убрать

**Команды Splinter для этого нет.** Журнал упомянут только в стартовой строке `bot.py:1246`. Команды бота — это
`/pulse`, `/ping`, `/rules`, и ни одна из них журнала не касается. Убрать можно правкой файла либо кодом.

**Рекомендация — пометка данными:** `python3 uborka.py apply <файл>` (текст в приложении). Что делает скрипт:
- находит РОВНО одну позицию по ключу `-1002751134848:76` + слоту «подшипники» + `at` 1790416264.777925;
- требует ровно прежний вид: `lost_no_km`, та же причина, `closed_at` 0.0. Иначе STOP, файл не тронут;
- ставит `state=void`, причину «снято по слову владельца 26.09.2026: работы не было — согласие на цену, не факт
  работ (#79, #82)» и `closed_at=now`;
- перечитывает файл перед записью: если служба успела писать, STOP;
- пишет атомарно (`.uborka.tmp` → `os.replace`, имя не пересекается с `.tmp` службы), тем же видом JSON, что
  `_wl_save`.

Проба на копии живым `works_persist.py` HEAD (`p7.out`):

| проверка | исходная копия | после `apply` |
|---|---|---|
| открытых (`open_items`) | 1 | **0** |
| `_wl_tick` (expire → report) | строка есть → `[ERROR]` | **строки нет** → старт пишет INFO «открытых нет» |
| `counts` | lost_no_km 1, written 4 | lost_no_km 0, written 4 (`void` не считается ни потерей, ни записью) |
| `lose` / `settle` по снятой | — | 0 / 0 — не трогают |
| новый честный приём «подшипники» в теме 76 | — | заводится (1), `settle` закрывает только новую; снятая остаётся `void` |
| `prune(keep=0)` | — | снятая остаётся — ротация её не выбрасывает |
| повторный `apply` | — | STOP, rc=1 |

- **Перезапуск не нужен.** `_wl_load` читает диск на каждом зове, в его докстринге сказано: «Кэша в памяти процесса
  нет намеренно». Следующий `_wl_tick` — старт, приём работ или выгрузка по пробегу — прочтёт правленый файл.
- **Не перепишет ли служба файл из памяти — нет.** Копии журнала в памяти нет. Буфер `_PENDING_WORKS` этой темы
  пуст: процесс 13:50:17 работ не откладывал. Остаётся гонка «служба прочла → мы заменили → служба записала
  прочитанное». Окно — миллисекунды внутри одного `_wl_*`, и только при приёме работ или пробеге в ту же секунду.
  Скрипт сверяет байты перед заменой, а проверка п.5 после правки ловит и этот случай.
- **Почему не прочие пути** (варианты #82 §7 и ручка модуля):
  - удалить строку — это удаление открытой позиции, против «ничего не удалять» и против устройства модуля
    («выбросить ОТКРЫТУЮ потерю он не умеет ни одной веткой»);
  - `written` — ложь «работа записана»;
  - код-исход `void` (#82 §7а) — коммит, тесты, перемотка и перезапуск ради одной строки. Пометка данными тем же
    литералом `void` с ним совместима: если исход позже оформят кодом, файл уже будет правильным;
  - ручка `WORKS_PERSIST=0` в файле настроек сервера плюс перезапуск — выключает журнал целиком вместе с защитой
    настоящих потерь;
  - ждать мира — позиция не закроется, пока работу не сделают.

## 4. Откат

- **Копия до правки** — рядом с файлом: `cp -p works_persist_state.json works_persist_state.json.bak-uborka-2609`.
  Имя под правилом `*.bak*` (строка 72 `.gitignore` сервера, `git check-ignore -v`), значит дерево останется чистым.
  Лежит на диске, а не в `/tmp`, чистка его не съест.
- **Проверка копии:** `cmp` rc=0 и равные sha256. На копии в пробе: `cmp` rc=0, sha `e652e947…` у обеих, JSON равен,
  позиций 5. Контроль вида: круг «load → dump» тем же видом, что `_wl_save`, даёт те же байты (`True`). Поэтому
  `revert` возвращает файл байт-в-байт.
- **Команда возврата одной строкой:**
  `python3 /tmp/podshipnikuborka2609/uborka.py revert /root/turbobaby-manager-bot/works_persist_state.json`.
  На копии: sha после `revert` = `e652e947…` = исходной,
  `cmp` rc=0; повторный `revert` → STOP rc=1. `revert` точечный: позиции, добавленные службой после правки, он не
  трогает.
- **Запасной откат копией** — только если sha живого файла всё ещё равен sha сразу после `apply`, то есть служба
  не писала: `cp -p works_persist_state.json.bak-uborka-2609 works_persist_state.json`. В пробе `cmp` rc=0. Иначе
  копия затёрла бы позиции, принятые после правки.

## Приложение — `uborka.py` (sha256 `61ce6b526458a0dd…`)

```python
"""0045-74n.2609: снятие ложной позиции журнала принятых работ Splinter — ПОМЕТКОЙ, а не удалением.

Позиция: тема 76, байк 4685, работа «подшипники», at 26.09.2026 09:51:04.777925 UTC (заведена 48ee30a
из согласия на цену, #79/#82). `apply` меняет ЕЁ исход lost_no_km → void (исход вне OPEN_STATES:
report/expire/lose/settle/accept его не видят, prune выбрасывает только written — строка остаётся навсегда).
`revert` возвращает ровно прежние три поля. Любое расхождение с ожидаемым — STOP, файл не трогается.
Запуск: python3 uborka.py apply|revert <путь к works_persist_state.json>
"""
import hashlib
import json
import os
import sys
import time

KEY, SLOT, AT = "-1002751134848:76", "подшипники", 1790416264.777925
WAS_STATE, WAS_WHY, WAS_CLOSED = "lost_no_km", "пробег так и не пришёл за 3ч", 0.0
VOID = "void"
WHY_VOID = "снято по слову владельца 26.09.2026: работы не было — согласие на цену, не факт работ (#79, #82)"

mode, path = sys.argv[1], sys.argv[2]
raw = open(path, "rb").read()
d = json.loads(raw)
hits = [i for i in d.get("items", []) if isinstance(i, dict) and i.get("key") == KEY
        and i.get("slot") == SLOT and abs(float(i.get("at") or 0) - AT) < 0.001]
if len(hits) != 1:
    sys.exit(f"STOP: позиций по ключу {len(hits)}, ожидалась ровно 1 — файл не тронут")
i = hits[0]
if mode == "apply":
    if (i.get("state"), i.get("why"), i.get("closed_at")) != (WAS_STATE, WAS_WHY, WAS_CLOSED):
        sys.exit(f"STOP: вид позиции {i.get('state')!r}/{i.get('why')!r} не тот, что при разборе — файл не тронут")
    i["state"], i["why"], i["closed_at"] = VOID, WHY_VOID, time.time()
elif mode == "revert":
    if i.get("state") != VOID:
        sys.exit(f"STOP: исход {i.get('state')!r}, а не {VOID!r} — возвращать нечего, файл не тронут")
    i["state"], i["why"], i["closed_at"] = WAS_STATE, WAS_WHY, WAS_CLOSED
else:
    sys.exit("режим: apply | revert")
if open(path, "rb").read() != raw:
    sys.exit("STOP: файл сменился во время правки (писала служба) — файл не тронут, повтори")
tmp = path + ".uborka.tmp"
with open(tmp, "w", encoding="utf-8") as f:
    json.dump(d, f, ensure_ascii=False, default=str)     # тот же вид, что у splinter._wl_save
os.replace(tmp, path)
print(f"{mode} OK · state={i['state']} · sha256={hashlib.sha256(open(path, 'rb').read()).hexdigest()}")
```
