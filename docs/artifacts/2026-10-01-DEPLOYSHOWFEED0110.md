## 3. Как откатить (ничего не удаляя)

**Показ** — перезаписать `show.conf` значением 0 (на вкл. понимаются только `1/true/yes/on`):
```
printf '[Service]\nEnvironment=WA_TG_MIRROR_SHOW=0\n' > /etc/systemd/system/wa-tg-mirror.service.d/show.conf
systemctl daemon-reload && systemctl restart wa-tg-mirror      # строка старта: «показ выключен»
```
Медиа продолжат качаться. Открытые темы останутся в группе. `show_start_id` в базе службы останется:
повторное включение уже не «первое» и не откроет темы по суткам назад.

**Splinter:**
```
cd /root/turbobaby-manager-bot
git revert --no-edit 4a4ab1b cf0f534 && systemctl restart splinter.service   # обе правки
git revert --no-edit 4a4ab1b && systemctl restart splinter.service           # только лента, одометр 0088 остаётся
```
Без кода (SPLTOPICFEED0110 §8): `TOPIC_FEED_CONTEXT=0`, затем `TOPIC_FEED=0` в серверном `.env` и
рестарт. Файлы `topic_feed/*.jsonl` при откате остаются и ни на что не влияют.
