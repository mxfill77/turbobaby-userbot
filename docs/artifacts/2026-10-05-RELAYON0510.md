  я по ошибке перенаправил вывод в `/dev/shm/.x`. Там 1371 байт: 8 строк старта 05:49:29 (выключатели, «ключ бота
  есть» и подобное, без ключей и текстов клиентов). Это tmpfs, в git и в каталоге проекта файла нет, после перезагрузки
  его не будет. Удалять запрещено, поэтому файл лежит. Если нужно убрать: `rm /dev/shm/.x` руками.
- **Гард отказал один раз:** чтение кода `wa_agent_svc.py` грепом с шаблоном про файл окружения он принял за обращение
  к секретам. Я не обходил и не повторял: доказательством осталась строка старта.
- **Попутно увидено, не трогал:** в живом дереве сервера лежит каталог `_rollprep_0510_tmp/clone` (не мой, от
  подготовки выкатки). Греп по дереву находит там вторую копию `wa_agent_tg.py`.
