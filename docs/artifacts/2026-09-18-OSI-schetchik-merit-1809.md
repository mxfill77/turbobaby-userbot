## 1. Чем меряет

**Место.** Цепочка такая:
- `vitrina_pc_run.py:561` `axes_of_day` делает три вызова `contour_digest_run.git_moves` (`contour_digest_run.py:231`);
- каждый вызов — это `git log --since=<00:00 UTC текущих суток> --pretty=format:%h %s -- <пути>`: по всему дереву `.`, по `AXIS3_PATHS` и по `BUSINESS_PATHS`;
- результат считает `vitrina_pc.axes_tally` (`vitrina_pc.py:437`): ось = |хеши оси|, бизнес = |хеши бизнеса|, обслуживание = |все − ось − бизнес|;
- строку печатает `vitrina_pc.axes_words` (`vitrina_pc.py:451`).

Списки путей (`contour_digest_run.py:56–60`) заведены коммитом `8238d91` 02.09 и с тех пор не менялись (`git log -L56,60`):
- ось — `pc_orchestrator.py`, `review_*.py`, `recon_*.py`, `expectations_pc*.py`, `done_judge_pc.py`, `content_product_verifier.py`, `queue_snapshot_pc.py`, `series_pc.py`, `contour_digest*.py`, `pretool_guard.py`;
- бизнес — `suggest.py`, `pricing*.py`, `price_*.py`, `delivery*.py`, `booking*.py`, `client_*.py`, `moderation*.py`, `bot.py`, `trainer*.py`, `fixtures/*`.

**Что признак «бизнес N» значит дословно:** «с 00:00 UTC сегодняшних суток в git лёг N коммитов, каждый из которых изменил хотя бы один файл, чьё имя подходит под один из десяти шаблонов, записанных 02.09».

**Откуда берётся.** Из места события, а не из чужого текста о нём: судятся пути в дереве коммита, слова сообщения не читаются (комментарий `contour_digest_run.py:53–55`). В этом смысле П3-запрет «из собственного текста» признак **не нарушает**. Но событие, которое он видит, — «коммит задел файл с таким именем», а не «бизнес двинулся».

Ещё три свойства, которые не видны по имени:
- **единица — коммит, а не заход**: 38 коммитов против 22 закрытых рядов. Заход с кодом и артефактом даёт два коммита, заход без коммита (ряд #64) не даёт ничего;
- **«обслуживание» — это остаток**, то есть «не опознан списками» (`vitrina_pc.py:99–105`), а не «обслуживание нас самих» в смысле рамки;
- **«за сутки» — с 00:00 UTC, то есть с 07:00 местного**, а не скользящие 24 часа. В 22:28 местного «сутки» охватывали 15 ч 28 мин.

Пересчёт теми же pathspec, что у кода (снято 18.09 ~00:30 местного): всего 38, ось 6 (`4a73522 d6ca969 5b355cb 7515d6c 2225e7f 2b61e43`), бизнес 0. Витрина в тот же момент показывала 6·0·32 — сходится.

## 4. Решение: счётчик прав или имя врёт

**Врёт имя.** Арифметика верна (38/6/0/32 сошлись с пересчётом), но все три слова строки обещают больше, чем меряется:

| слово в строке | обещает | меряет |
|---|---|---|
| «заходов за сутки» | заходы (рамка 739: «СЧЁТ ЗАХОДОВ ПО ОСЯМ») | коммиты с 00:00 UTC; 38 коммитов на 22 ряда, ряд без коммита не виден |
| «бизнес» | «чинит данные бизнеса» (733–734) / «бизнес двинулся» (737–738) | коммит задел файл под одним из 10 шаблонов 02.09 |
| «обслуживание» | «обслуживание нас самих» (734) | не опознан ни одним списком: сюда же уходят новый код бизнеса и все артефакты |
| «ось (этап 3)» | рост этапа 3 (852–854) | коммит задел файл под одним из 10 шаблонов; `pretool_guard.py` в нём, хотя рамка называет гард обслуживанием |

**Штабу тоже нужна поправка.** Слово «бизнес» рамка использует в двух смыслах:
- **направление захода** (733–734). В этом смысле 8 рядов экзамена — не обслуживание нас самих, и Штаб прав;
- **исход** «бизнес двинулся» (737–740, на нём стоит правило «ТРИ ЗАХОДА ПОДРЯД БЕЗ ДВИЖЕНИЯ БИЗНЕСА = СТОП»). В этом смысле 17.09 не двинулось ничего и у экзамена: уроки живого набора «на ответы бота не действуют» (`96f984c`), кейс 23 не собран, живой агент примет кнопки только после «обновись» (`a67e676`).

Ноль счётчика не мерит ни того, ни другого: он совпал с исходом случайно и разошёлся с направлением.

**Самый дешёвый способ, чтобы имя совпало с замером.** Замер не трогать, переименовать то, что уже меряется, в обоих местах печати:
- строку витрины (`vitrina_pc.axes_words`, `AXIS_*`) и тест `test_vitrina_pc.py:739–745`;
- строку сводки `contour_digest_run.section_axis` («бизнес ДВИГАЛСЯ / за окно не двигался»).

Новая форма строки: «коммитов с 00:00 UTC: по списку оси N · по списку бизнеса N · вне списков N (новые файлы: имена)».
- «Вне списков» печатается с именами файлов верхнего уровня, не из `docs/`. Тогда устаревание списка становится видно: 17.09 строка назвала бы `exam_show.py`, `exam_set.py`, `exam_shots/`, `pc_agent.py`, `cut_mark_scan.py`.
- Слово «обслуживание» уходит: остатку его не выдавать.

Цена — **1 заход** (чистая логика плюс один `git log --name-only` в руках витрины и тесты; масштаб правки витрины 63-r).

**Ограничения этого предложения:**
1. Такая правка не даёт замера «бизнес двинулся». У того своих источников три, по числу слов рамки: падения клиентского бота, сверки данных, черновики в группе модерации. Ни один не git. Цена — **НЕИЗВЕСТНО**, не меньше одного захода разведки.
2. По рамке (206–209) это не первый случай класса «имя обещает больше замера»: первым назван `operational_change`, этот — не меньше второго. Второй случай — «разведка списком», заплата до правила запрещена. Честная цена по рамке — **2 захода**: разведка списком таких имён на полосе ПК, затем правка по правилу. Рамка на 17.09 без правки — **СТОП каждые три захода**: витрина весь день показывала бизнес 0 (п.5).

## 5. Побочное: на что влияет и кто читает

- **Решений кода — ноль.** Число уходит только в слова:
  - раздел «ОСИ» витрины: сообщение в теме и полный текст в `pulse_pc`, `vitrina_pc_run.write_pulse`;

- **Механический эффект.** Раздел «ОСИ» входит в тело витрины (`vitrina_pc.py:964`), а подпись смены считается по полному телу (`vitrina_pc.py:982–991`). Каждый новый коммит суток меняет подпись: витрина правит сообщение и пишет `pulse_pc`.
- **Читатели — люди.** Главный читатель `pulse_pc` — Штаб (артефакт 63-p, строка 66); `devbot` `pulse_pc` не читает (там же, строка 99). Витрину в теме видит владелец. Серверных читателей — **НЕИЗВЕСТНО**: сервер по заданию не трогали.
- **Решения рамки, которые питает эта строка:**
  - «СУТКИ БЕЗ ДВИЖЕНИЯ ОСИ = СИГНАЛ» (735);
