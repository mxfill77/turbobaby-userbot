## 1. Премиса проверена, четыре пункта — три живьём, один по коду

### П1. Витрина читала узел ПО ИМЕНИ, и имя не разрешается

Живая проба (`brain_writer.read_text(name='shtab_vitrina')`, 05.09):

```
BrainWriterError: ИМЯ НЕ РАЗРЕШЕНО: 'shtab_vitrina' → канон 'shtab_vitrina'.
В живом реестре такого ключа нет (ключей 37). Похожие ключи: shtab_box, shtab_frame.
Адресуй по file id (--id), назови ключ реестра точно — либо ЗАРЕГИСТРИРУЙ файл
под ключом (--register КЛЮЧ=ID), и правило канона подхватит имя само
```

**ПОДТВЕРЖДЕНО.** Сломан был РОТ, а не панель: отказ витрина печатала честно,
числа при этом собирались исправно.

### П2. Документ с ровно этим именем лежит в ПАПКЕ, и формат уже читаемый

Живая проба `brain_writer.list_folder(prefix='shtab_vitrina')`:

```
ok=True  count=1  truncated=False
  файл: name='shtab_vitrina'  id=1-kp-uUp7xynNY…  mime=text/plain
```

Тело по file id — **988 символов**; нынешний разборщик `vitrina_pc.parse_shtab`
на нём даёт:

```
{"ok": true, "why": "", "day": "2026-09-03", "разделы": ["goal", "now", "stuck"]}
```

**ПОДТВЕРЖДЕНО.** Строка даты (`дата = 2026-09-03`) и три маркера в двойных
квадратных скобках — ровно тот формат, который разборщик уже понимает. Разборщик
не менялся ни строкой.

### П3. Ящик ходит в ТУ ЖЕ папку — дорога взята у него целиком

По коду (греп + чтение, не по памяти):

| шаг | у ящика | у витрины ПОСЛЕ правки |
|---|---|---|
| перечислить папку | `shtab_box_run.read_folder(prefix)` → `brain_writer.list_folder(prefix=…)` | **та же функция** `sbr.read_folder(prefix=vp.SHTAB_NODE)` |
| взять тело | `shtab_box_run.read_doc_text(id)` → `brain_writer.read_text(doc_id=…)` | **та же функция** `sbr.read_doc_text(hits[0]["id"])` |

**ПОДТВЕРЖДЕНО, и это ответ предсмертному взгляду.** Задание назвало провалом
«документ прочитают вторым способом мимо ящика». Второй дороги не заведено:
витрина зовёт те же две двери. Цена вопроса измерена не нами — в `read_folder`
живёт правило «**усечение = отказ, а не короткий список**» (замер 03.09: `limit=3`
на 49 файлах вернул не три первых по алфавиту, а произвольный кусок,
отсортированный так, что выглядит началом). Свой поход в ту же папку это правило
бы не унаследовал и разошёлся бы с ящиком **молча**.

### П4. Файл витрины в клиентское замыкание не входит

`client_contour.closure()` — **30 файлов**; `vitrina_pc.py`, `vitrina_pc_run.py`,

## 2. Что изменено — одно место

`vitrina_pc_run.read_shtab(node=None, reader=None, lister=None)`:

```
БЫЛО:   brain_writer.read_text(name=SHTAB_NODE)          → отказ реестра всегда
СТАЛО:  read_folder(prefix=SHTAB_NODE) → точное совпадение имени → read_doc_text(id)
```

Имя берётся **из существующей константы** `vitrina_pc.SHTAB_NODE`; числовой адрес
документа не зашит нигде — это проверяет тест, читающий исходники обоих файлов
витрины и требующий отсутствия в них id.

**Четыре отказа названы ПРИЧИНОЙ, а не пустотой** (пункт 3 задания), каждый едет
в `why` и оттуда — в текст всех трёх частей:

1. папка не перечислена (в т.ч. **усечена**) — причина строкой от `read_folder`;
2. документа с таким именем в папке нет — с числом детей, попавших под префикс;
3. имя несут **два** документа (Drive это разрешает) — не берём ни один, тем же
   консервативным отказом, что у `shtab_box.parse_folder` на двойниках;
4. тело не прочитано либо пусто.

**Что НЕ менялось** (прямой запрет задания): разбор частей `parse_shtab`, потолок
части `SHTAB_PART_MAX=400`, правило «раздела нет — так и сказать» (`NO_SHTAB`),
возраст слов `SHTAB_STALE_DAYS`. Файл `vitrina_pc.py` не тронут ни строкой.

Отдельно: сосед по началу имени (`shtab_vitrina_old`) документом **не считается** —
отбор моста по префиксу нестрогий, поэтому совпадение имени сверяется точным
равенством. Закрыто тестом.

  в единственной копии.

• ЭТАП И КУДА ИДЁМ → Штаб: Этап 3: оркестратор как управляемый агент. Мера — число

N сут назад» пока нет. Он появится сам на третьи сутки без правки Штаба, и это
работающий, а не спящий замок.

## 6. Границы, названные честно

- Витрина **правится своим витком** демона: сообщение в теме обновится, когда
  демон подхватит коммит и соберёт факты. Здесь не перезапускалось ничего.

- Документ живёт **вне реестра моста**. Зарегистрируй его кто-нибудь ключом —
  старая дорога тоже заработала бы, но вторая дорога заводиться не должна:
