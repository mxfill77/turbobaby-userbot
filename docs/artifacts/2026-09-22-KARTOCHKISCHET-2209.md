## П.2 — регистрация (сделано, commit `3ca1abcd`)

Добавлен файл `pc_orchestrator.cards_ledger.jsonl` (JSONL, под `*.jsonl` в `.gitignore`). В нём одна
строка на событие, и пишется она в момент события:

* `показана` — `{ts, event, task, class, object, op, src}`. Пишется в двух местах, в обоих только
  после расписки моста о доставке:
  * ветка `needs_approval` в `process_new`, источник `маркер-гарда`;
  * `_revizor_post_owner_card` (создание и правка), источник `ревизор`.
* `ответ` — `{ts, event, task, class, answer, answered, src}`. Пишется в трёх местах:
  * `process_card_terminals`, для тех же исходов, что уходят в журнал;
  * `process_approved`, когда ревизорская карточка «принято»;
  * `_revizor_harvest_card_answers`, для отказа и истечения.

**Признак операции берётся из места события.** Параметра `op` у `shown_row` нет. `op=True` даёт
только источник `маркер-гарда`, а его зовёт одна ветка демона, куда управление приходит только
через `_detect_needs_approval`. Та признаёт карточкой только файл-маркер, который гард пишет сам
при перехвате настоящего вызова инструмента, со своим `run_token`. Слова «Класс операции: env» в
тексте карточки ревизора признак не поднимают: это закреплено тестом. Строк кода, которые пишут
`SRC_GUARD`, ровно одна; тест проверяет и это, и то, что строка стоит после расписки.
«Истекло» ответом не считается (`answered=false`). Объект проходит `safe_object`: имя, по которому
виден секрет, заменяется целиком. Текст карточки в строку не попадает, у ревизора не передаётся
даже объект, потому что в тексте его карточки есть выдержки из переписки. Откат: `CARD_LEDGER_OFF=1`.
Счёт выводится командой `python card_ledger_pc.py` (только чтение).

## П.4 — гашение: НЕ сделано, развилка

По числам единственный класс без операции за окно — **«ревизор»** (16 из 16 карточек `op=0`). По
правилу задания его пора переводить в суточную сводку. Не применено по трём причинам:
1. остановка по арифметике;
2. собственное окно прибора пустое, и 16 из 16 сняты из логов, а не прибором;
3. **гашение снимает кнопку «нет»**. У ревизора она покупала настоящую вещь: 3 тапа записали
   вердикты «ложная». В сводке кнопки нет, и отвергнутые находки начнут возвращаться.

Развилка для владельца или Штаба:
* **(а)** перевести ревизора в сводку и потерять «нет» с вердиктами. Ещё нужен сток «суточная
  сводка»: готового для этого класса нет, ближе всего `contour_digest`.
* **(б)** оставить показ, пока прибор не наберёт своё окно (например, 7 суток).

Рекомендация: **(б)**. Настоящий кандидат на гашение — `🔔`: 169 за 18 суток при наблюдаемых парах с
`🔴`. Но сначала его надо вшить в счёт в месте события.
