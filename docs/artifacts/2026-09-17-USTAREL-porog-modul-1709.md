## 1. Модуль — `node_age_pc.py`

Чистый: импортирует только `calendar`, `math`, `re`, `time` (прибито тестом `test_module_is_pure`).
Моста и диска не зовёт. Времени изменения мост не отдаёт, поэтому штамп берётся из текста узла.

| узел | как достаётся штамп | порог | откуда число |
|---|---|---|---|
| `pulse` | первая строка `ГГГГ-ММ-ДД ЧЧ:ММ` (UTC) | **3074 мин** | 63-p: p99 184398 с |
| `pulse_pc` | `числа менялись последний раз: … UTC` | **58 мин** | 63-p: p99 3461 с |
| `cowork_log` | САМЫЙ СВЕЖИЙ из штампов строк `<ТИП> ГГГГ-ММ-ДД ЧЧ:ММ UTC` (порядку строк не доверяем) | **162 мин** | 63-r, п.4 |
| `cc_log` | то же | **2233 мин** | 63-r, п.4 |
| `shtab_vitrina` | `дата=ГГГГ-ММ-ДД`: известны только сутки, возраст считается от конца суток (нижняя граница) | **нет** — только возраст | замер не снялся, п.4 |
| `queue_state_pc`, `queue_state` | `снято: … UTC` или `последний верный снимок: … UTC` (шапка «НЕ СВЕРЕНО») | **нет** — только возраст | порог 47/62 мин законен только вместе с R4, а R4 не поставлен |

Функции: **`age_line(node, text, now)`** собирает строку возраста, **`decide(node, text, now)`** решает,
показывать ли содержимое (`render` — показ целиком).
Исходы у узла с порогом: **`свежо`** — показано, первая строка
`<узел> · снято <время UTC> · <возраст> назад (порог N мин)`; **`устарело`** — вместо содержимого
`⚠️ <узел> УСТАРЕЛ: снят …, … назад (порог …, замер …) — содержимое не показано`; **`неизвестно`** —
штампа нет, он не разбирается или позже «сейчас» больше чем на 5 мин:
`⚠️ возраст <узел> неизвестен (<причина>) — содержимое не показано`. Этот исход отказывает так же, как
«устарело», и свежестью не считается.
Узел без порога и узел вне таблицы получают названный НЕ-исход `не судится`: содержимое показывается,
строка возраста говорит «порог не замерен — свежесть не судится» или «вне таблицы возраста».

## 3. Отрицательный тест тройной (дословно, `test_node_age_pc.py`)

```python
NOW = _ts("2026-09-17 14:40")
BODY = "ЖДЁТ ВЛАДЕЛЬЦА\n• #49 секретное-содержимое-витрины"


def _pulse_pc(stamp):
    return "ВИТРИНА ПОЛОСЫ ПК · одно сообщение\nчисла менялись последний раз: %s UTC\n\n%s" % (stamp, BODY)


FRESH_TEXT = _pulse_pc("2026-09-17 14:11")          # 29 мин при пороге 58
AGED_TEXT = _pulse_pc("2026-09-17 12:11")           # тот же узел, штамп состарен на 2 ч → 149 мин
BROKEN_TEXT = _pulse_pc("2026-13-45 25:61")         # штамп на месте, но разобрать нечего


class TestTriple(unittest.TestCase):
    """П.3: свежо → показано со временем; состарено → содержимого нет; испорчено → третий исход."""

    def test_fresh_is_shown_and_carries_time(self):
        got = na.decide("pulse_pc", FRESH_TEXT, NOW)
        self.assertEqual(got["outcome"], na.FRESH)
        self.assertTrue(got["show"])
        self.assertIn("снято 2026-09-17 14:11 UTC", got["head"])
        self.assertIn("29 мин назад", got["head"])
        shown = na.render("pulse_pc", FRESH_TEXT, NOW)
        self.assertTrue(shown.startswith("pulse_pc · снято 2026-09-17 14:11 UTC"), shown)
        self.assertIn("секретное-содержимое-витрины", shown)

    def test_aged_stamp_hides_content(self):
        got = na.decide("pulse_pc", AGED_TEXT, NOW)
        self.assertEqual(got["outcome"], na.STALE)
        self.assertFalse(got["show"])
        self.assertIn("УСТАРЕЛ", got["head"])
        self.assertIn("порог 58 мин", got["head"])
        shown = na.render("pulse_pc", AGED_TEXT, NOW)
        self.assertNotIn("секретное-содержимое-витрины", shown)
        self.assertIn("содержимое не показано", shown)

    def test_broken_stamp_is_third_outcome_not_fresh(self):
        got = na.decide("pulse_pc", BROKEN_TEXT, NOW)
        self.assertEqual(got["outcome"], na.UNKNOWN)
        self.assertNotEqual(got["outcome"], na.FRESH)
        self.assertFalse(got["show"])
        self.assertIn("возраст pulse_pc неизвестен", got["head"])
        self.assertNotIn("секретное-содержимое-витрины", na.render("pulse_pc", BROKEN_TEXT, NOW))
```

## 4. Пороги, которых не было — сняты тем же методом (промежутки между записями)

Метод 63-p: штампы записей → промежутки → p99 (ближайший ранг) → вверх до минуты. Добавлено правило:
**меньше 100 промежутков — порога нет**, потому что p99 по такой выборке совпадает с максимумом
(`limit_from`, прибито тестом). Штампы в журналах минутные, записи одной минуты сливаются в одну.

| узел | источник штампов | записей | сут | p50 | p95 | **p99** | max | порог |
|---|---|---|---|---|---|---|---|---|
| `cowork_log` | живой текст узла, 2 129 799 симв., 8033 штампа (32 строки без штампа) | 5727 | 51.0 (28.07–17.09) | 180 с | 1800 с | **9720 с** | 249 840 с | **162 мин** |
| `cc_log` | живой текст узла, 706 729 симв., 691 штамп | 659 | 62.5 (17.07–17.09) | 1260 с | 35 280 с | **133 980 с** | 387 840 с | **2233 мин** |
| `shtab_vitrina` | смены слов Штаба в 1345 бэкапах `pulse_pc` (03.09–17.09; наблюдений 1213, «не прочитан» 131) | 4 смены | 1.3 | 4165 с | — | 106 003 с | 106 003 с | **НЕ СНЯЛСЯ** |

**`shtab_vitrina` идёт только с показом возраста, без отказа.** Смен 4 (08.09 08:52, 08.09 09:15,
09.09 14:42, 09.09 15:51 UTC), промежутков 3. Часть смен — правки самой витрины 08–09.09, а не записи
Штаба. Штамп узла к тому же суточный. Порог из трёх чисел законом не является.

Слепки очереди тоже идут **без отказа**, но причина другая: число в 63-p есть, только оно законно
лишь с R4. Без R4 p99 (76 мин / 7 ч) давал бы ложный «устарел» 24.6 % / 22.7 % времени.

Замеченное попутно, без разбора: последний штамп `cc_log` — **2026-09-17 13:50 UTC**. Узел пишется и
после 09.09, хотя сессий сервера с 09.09 нет (63-p). Кто пишет — НЕИЗВЕСТНО.
