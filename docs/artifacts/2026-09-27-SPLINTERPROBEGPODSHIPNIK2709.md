1. **Один вид или два.** Колёса и рулевой — одна проверка («подшипники») или две строки. Рекомендую одну: так
   сказано в правиле.
2. **Пустая клетка.** Воздушный фильтр без записи сейчас показывает «❗ не делалось» при любом пробеге.

   нет записи и пробег < 20000 → «ещё N км до первой проверки»; ≥ 20000 → «пора».
3. **А или Б** — где живёт регистр.

### 5.2. (б) Число в тексте без фото одометра — не показание: Splinter переспрашивает

**Правило одной фразой.** Число из текста пишется как показание одометра только при двух условиях сразу:
- автор доверенный (`TRUSTED_AUTHORS`, 270);
- форма явная: слово «пробег/одометр/mileage/odo/ไมล์» рядом с числом, либо голое число в ответ на вопрос
  Splinter о пробеге (эта дверь уже есть — `handle_mileage_confirm`).

Во всех прочих случаях, включая порог «после/через/каждые/до/от/after/every/หลัง/ทุก N», Splinter ничего не
пишет. Он один раз, RU+TH, спрашивает кнопками: «📟 N — это пробег сейчас, по приборке?»
[✅ Да, пробег сейчас] [✏️ Нет, это не пробег].

Это та же форма, что в правиле владельца 27.09 из 0048-74q (§5 SPLINTERPEREPROS2709):
- переспрос кнопками, а не текстом — кнопка знает автора (`q.from_user`);
- метка переживает перезапуск (`svc_tokens.json`);
- голое число в теме не уходит в чужую дверь (фаза 2 / коррекция / E2a).

**Сверка со свежим одометром.** Если свой одометр свежий (`_odo_known_fresh`, окно 60 мин) и N с ним не
совпадает, в вопрос добавляется «15 мин назад подтверждено 19130». 27.09 этого хватило бы, чтобы увидеть
ошибку глазами.

**Куда встраивать.**
- **Решение — чистый модуль** (например `text_odo.py`, импорт только `re`):
  `verdict(text, km, trusted, fresh_km=None) → READING | ASK`.
- **Руки** — в `_handle_servicing`, один раз после разбора (9458):
  - при `ASK` из `parsed` убирается `mileage`;
  - тем самым одним местом гаснут все четыре потребителя: `_km_for_record` → «события» (9618/9652),
    ТО-трекер (9744), кнопки фиксации группы B (9756 — сейчас «замените фильтр после 20 000» предложило бы
    доверенному записать кол.L = 20000), текст приёмки возврата (9686);
  - вопрос уходит через `_hint_send` новым видом, замок повторов — по числу;
  - «Да» доверенного → `_odo_confirmed` + `_after_mileage` (путь фото байт-в-байт);
  - «Да» не доверенного → просьба фото приборки;
  - «Нет» → одна строка «понял, пробег не трогаю».
- **Ручка отката** — по образцу `_talk_stage_on` (например `TEXT_ODO_ASK`, умолчание — вкл).
- **Названная цена.** Из 11 записей фона 6 похожи на явное «пробег N» доверенного — они пройдут, как раньше.
  4 без слова «пробег» получили бы вопрос. Одна (27.09) не записалась бы вовсе.
