### Почему пару задаёт файл, доказано без его чтения

- Процесс теста получает окружение из оболочки ssh, из самого теста и из `load_dotenv(REPO/.env)`.
- Оболочка ssh: `ORCH_MODEL` и `ORCH_MODEL_FALLBACK` **не заданы** (проверка `[ -n "${ORCH_MODEL:-}" ]`,
  вызов 21:14:21 UTC).
- Сам тест ставит только `BRIDGE_URL`, `BRIDGE_TOKEN`, `PLAN_ADAPT`, `CURATOR` и `EXECUTOR_MODEL`.
- Дефолты влитого кода 5-5 / 5, а тест увидел другие значения по **обоим** именам. Остаётся один
  источник: файл настроек репо, и в нём есть **обе** строки. Демон под systemd грузит тот же файл тем же
  вызовом.
- Нынешние значения этих строк известны по баннеру живого демона: `claude-opus-5` и `claude-opus-4-8`.
  Сам файл не открывался.

## Что нужно сделать руками (класс `env`, красное, задание его запрещает)

Одной ssh-сессией на сервере, **с ПК или из Termux, а не из задачи демона**. Исполнитель, запущенный
демоном, сидит в его cgroup и погибнет от собственного рестарта.

```
cd /root/turbobaby-manager-bot
cp .env .env.bak-models55-2409
# в .env поменять ДВЕ строки (сейчас claude-opus-5 и claude-opus-4-8):
#   ORCH_MODEL=claude-opus-5-5
#   ORCH_MODEL_FALLBACK=claude-opus-5
git merge --ff-only origin/pk-golovy-55-2409
ORCH_TEST_MODE=1 venv/bin/python3 tests/test_orchestrator_model.py   # ждать «ИТОГ: ВСЕ PASS» (15/15)
ORCH_TEST_MODE=1 venv/bin/python3 tests/test_executor_model.py       # ждать «ИТОГ: ВСЕ PASS» (20/20)
systemctl restart orchestrator-daemon
systemctl is-active orchestrator-daemon splinter
grep -a "ДЕМОН СТАРТ" orchestrator_daemon.log | tail -1
# ждать: model=claude-opus-5-5, fallback=claude-opus-5, executor_model=claude-opus-5-5
```

`systemctl restart splinter` не нужен: splinter не импортирует `orchestrator_daemon`.

**Откат:** вернуть две строки из `.env.bak-models55-2409`, затем `git reset --keep 2e98f5c` и
`systemctl restart orchestrator-daemon`. Баннер снова покажет `claude-opus-5 / claude-opus-4-8`.

**Порядок важен.** Если влить ветку без двух строк, гейт сервера станет красным. Если поменять строки
без влития, баннер покажет 5-5/5, но тесты `2e98f5c` станут красными: литералы в них старые.
Поэтому строки и влитие делаются вместе.
