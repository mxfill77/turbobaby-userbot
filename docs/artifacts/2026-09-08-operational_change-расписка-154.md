## п.2 Что признак значит ПО КОДУ, а не по имени

Выставляет его `review_auto.operational_change` (`review_auto.py:310–323`), дословно:

```python
def operational_change(claimed, verified):
    claimed = list(claimed or [])
    verified = [c for c in (verified or []) if c in claimed]
    if verified:
        return True, "commit_verified"
    if claimed:
        return False, "commit_unverified"
    return False, "no_commit_claimed"
```

Условие ровно одно, и оно текстовое:

1. `claimed_commits` (`review_auto.py:297`) — **регулярка по тексту отчёта**
   (`review_auto.py:125`): `\b(commit|коммит|коммита|коммите|коммитом|hash|хеш|хеша)\b`
   и рядом 7–40 hex. То есть «объявленный коммит» = **слово-указатель плюс хеш в прозе**.
2. `verify_commits` (`review_auto_run.py:118–131`) — `git cat-file -e <sha>^{commit}`,
   то есть **существование объекта в дереве. Ни автора, ни времени, ни содержимого.**
3. Пересечение непусто → `True, "commit_verified"`.

**Дословный смысл признака:** «в тексте отчёта рядом со словом *коммит* стоял хеш,
и такой объект в дереве есть». Не «менялся боевой код», не «менялось операционное
состояние» в том смысле, в каком его определяет запретный блок самого задания
(процессы, живые таблицы, деньги, дети контура, выкатки, удаления). Пакет говорит
это про себя вслух: «коммит подтверждён **только фактом существования в дереве —
не содержанием**».

**Меняется ли он от чтения — да, и штатно.** Признак сделанности разведзадачи
требует дословно: «**артефакт закоммичен**». Ритуал репозитория добавляет второй
коммит — тело журнальной записи. Разведка, исполнившая задание идеально, обязана
породить два docs-коммита и назвать их в отчёте словом «commit» — то есть **поднять
признак собственным послушанием**.

## п.5 Второе дело: вырождение колонки хешей в пакетах

**Срез:** `docs/review_outbox/*.md` — **122** файла. Из них **121** имеет таблицу

Вырожденной считаю колонку, у которой `sha256 источника == sha256 выдержки`
**у всех источников пакета разом** — то есть выдержка равна файлу целиком, и
колонка не несёт ни бита сверх соседней.

| замер | число |
|---|---|
| пакетов с таблицей источников | 121 |
| **колонка вырождена у всех источников разом** | **31** |
| доля от пакетов среза | **25.6 % (31 / 121)** |
| источников у вырожденных пакетов | от 1 до 4 |

Каждый четвёртый пакет, уходящий внешнему, несёт две колонки хешей, попарно
равные во всех строках. Это замер; правки не делал и не предлагаю решением.
