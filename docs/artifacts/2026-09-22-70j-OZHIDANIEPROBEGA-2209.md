## п.5 — ТРЕТИЙ ИСХОД: ПРОВЕРЕН НАМЕРЕННО СОЗДАННЫМИ СОСТОЯНИЯМИ

«Проверить невозможно» → **`неизвестно` с причиной**, и ни одна ветка не превращает это в
«получен» или «в порядке». Пять состояний созданы намеренно:

| намеренное состояние | причина в вердикте |
|---|---|
| мост не ответил (`ok=False`) | «источник не прочитан: мост не ответил» |
| `свой одометр` есть, а `updated_at` отсутствует | «у измерения нет времени — с просьбой не сравнить» |
| часов нет (`now_utc=None`) | «часов нет — возраст не берётся» |
| у просьбы нет времени | «у просьбы нет времени — сравнивать не с чем» |
| источник назван словом не из словаря | «происхождение пробега не названо» — умолчание ЗАКРЫТОЕ |
| ожидания нет вовсе (`exp=None`) | «ожидания нет — судить нечего» |

`test_ни_одно_неизвестно_не_называется_получен` гоняет пять из них разом и считает:
исходов `получен` — **0**, исходов `неизвестно` — **5**. Мутант M3 (третий исход объявляется
«получен») краснит **7 проверок** — это самый заметный замок набора.

Отдельно названо, чего здесь НЕ делается: `_parse_utc` на неразобранном времени возвращает `None`
и **не подставляет «сейчас»**. Подстановка превратила бы «не знаю когда» в «только что», то есть

измерен обоими мутантами — M6 показывает 8 вместо 3, а выбор «событие, а не состояние» даёт
