## 5. Признак, замирающий в простое, живостью не считается (пункт 2 задания)

периодическими в простое (§2.1). Нагрузочные кандидаты отвергнуты ПОИМЁННО и в коде
(`KID_REJECTED`, тест `test_the_rejected_signs_are_named_in_code_and_none_of_them_is_used`):

| отвергнут | почему |
|---|---|
| `userbot.log`, `logs/userbot_stderr.log` | болтовня библиотеки о ЧУЖОМ трафике каналов (1 сдвиг за 180 с): нет трафика — нет строк |
| `moderation_bot.log`, `logs/moderbot_stderr.log` | событийный: 0 сдвигов за 180 с при заведомо работающем боте — «лежал 5 ч 54 м» родилось ровно отсюда |
| `suggest_pending.jsonl`, `pricing.userbot_listen.log` | продукт КЛИЕНТСКОЙ РАБОТЫ: 0 сдвигов без клиента |
| `moderation_ipc.db` (mtime) | ОБЩИЙ канал: писателей трое |

## 6. Ключ читается ТОЛЬКО на чтение, с суммой до и после (пункт 5 задания)

Чтение живёт в **глазу О5** — единственном файле слоя, которому позволен `sqlite3`, и позволен под
`ast`-инвариантом. Разрешение получено **сужением** прежнего замка, а не его ослаблением:
соединение в модуле по-прежнему **ровно одно** (`_ro_conn`, `test_every_connection_is_opened_read_only`),
глаголов записи в SQL нет ни одного, руки слоя `sqlite3` по-прежнему не импортируют.

```
$ venv/Scripts/python.exe client_silence_pc.py
источник: D:\turbobaby-bot\moderation_ipc.db
прочитан: да
ОТПРАВЛЕНО КЛИЕНТУ: 0 (последнее: None)
попыток без доставки: 0 · взведено к отправке: 0 · всего черновиков: 483
разрез по статусам: {"posted": 447, "rejected": 21, "test_held": 15}
второй свидетель (suggest_pairs.jsonl): прочитан=да строк=0, отправок=0, последняя=None (файла нет — ни одной попытки отправки не записано)
СВОЙ продукт модербота (meta['heartbeat']): 2026-08-18T15:36:54.768186+00:00
контрольная сумма файла до и после чтения: СОВПАЛА — файл не тронут (общий канал — сведение, mtime 1787067414.7731874)
```

**Честно о том, что сумма доказывает, а что нет.** У файла живой писатель с тиком 5 с, поэтому
расхождение сумм не различает «подвинули мы» и «подвинул он» — и прибор этого не скрывает:
`sha_same=True` значит «за наше окно файл не менялся вовсе», `False` — «подвинули, и хешом
авторства не установить», `None` — «сумму снять не удалось». Когда сумма разойдётся,
доказательством служит **не хеш, а режим**: `mode=ro` отбивает любой глагол записи на уровне ОС.
Это проверено ЖИВЫМ отказом на настоящей базе в
`test_the_key_is_read_only_and_the_checksum_is_taken_before_and_after`:

```
UPDATE meta SET v='подделка' WHERE k='heartbeat'  →  sqlite3.OperationalError: attempt to write a readonly database
sha256 файла после отбитой записи == sha256 до
```

Боевая база при этом **не писалась ни разу**: живой отказ проверяется на проверочной сущности во
временном каталоге, а с боевой снято только чтение ключа и две контрольные суммы.

Против переименования ключа заведён `fail-closed`-замок: имя `meta['heartbeat']` держится у
наблюдателя копией и сверяется с ИСХОДНИКОМ писателя `ast`-ом
(`test_the_key_of_the_own_product_is_the_one_the_writer_writes`) — переименуют у писателя, обязано
покраснеть здесь, а не молча превратиться в вечное «неизвестно» о живом ребёнке.

## 7. Три исхода по КАЖДОМУ ребёнку отдельно (пункт 4 задания)

Слова прежние и не переводятся в «жив/не жив»: «жив» этот слой про ребёнка не говорит никогда.
Лестница `kid_state` — восемь ветвей, и порядок их часть смысла:

```
1. признака нет в таблице            → неизвестно
2. факта нет вовсе                   → неизвестно
3. порог 0                           → неизвестно (объявленный откат)
4. признак нагрузочный               → неизвестно ВСЕГДА (пункт 2 задания)
5. процесса из лока в системе НЕТ    → РАБОТЫ НЕТ          ← правка живого случая 18.08
6. источник не прочитан              → неизвестно
7. тишина > предела                  → работы нет; иначе продукт свеж и нужна живая проба
8. тишина не измерена, возраст велик → неизвестно (сон машины молчанием не является)
```

Сквозной тест показывает все три слова разом, от файлов до строки:

```
pc_agent — делает работу (свой продукт 1 с назад) ;
userbot — работы нет (процесса из лока в системе нет) ;
moderation_bot — неизвестно (…)
```
