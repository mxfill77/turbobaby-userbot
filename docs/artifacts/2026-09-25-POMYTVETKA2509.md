## 5. Чего не сделано / остатки

- **На живой Splinter не применено** (запрет задания): ни слияния в main, ни рестарта. Применение — отдельным
  заданием: ветка `splinter-pomyt-vetka-2509` на GitHub, коммит `744619b`.
- Тесты сервера на ПК не гоняются: `bridge_client` импортирует `fcntl`, на Windows его нет — все прогоны на сервере.
- «Полный набор живого корня зелёный» в буквальном смысле не показан: живое дерево трогать нельзя, а клон в `/tmp`
  даёт 29 красных среды (п. 4); доказательство — равенство красных у родителя и у ветки и отсутствие связи с
  диффом. Зелёный живой набор получится только прогоном после применения.
- Остатки кода (из раздела CLAUDE.md ветки, не чинились): поле снимка `disassembled` живьём не проверено; тайских
  слов возврата в `_RETURN_WORDS` нет — такой возврат виден только через CRM и свой след; память «сервис в теме»
  живёт в процессе и стирается рестартом (после него решает своя строка работ в «событиях»); замок «один раз за
  цикл» ключуется по (чат, тема, байк) — снимок того же байка в ДРУГОЙ теме дал бы второй совет; цикл без CRM —
  местная дата, поэтому «вернул» сегодня и «вернул» завтра про один возврат без строки CRM — два цикла.
- Цена включённой ручки: грязный снимок без решения по сообщению/памяти стоит до четырёх чтений моста
  (`read_events`, `service_pending_get`, `find_bike`, `clients filter=all`) — лениво, по порядку силы.
