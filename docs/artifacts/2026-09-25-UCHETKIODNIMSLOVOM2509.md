## 2. Что построено

**Реестр (`accounts.py`, его импортирует демон; чистый: `io/json/os/re/collections` + `profile_choice`).**

```json
{"form": 1, "builders": 3,
 "accounts": {"1": {"profile": "ОСНОВНОЙ",            "slot": "A", "label": "основная"},
              "2": {"profile": "D:\\claude_profile_2", "slot": "B", "label": "вторая"},
              "3": {"profile": "D:\\claude_profile_3", "slot": "",  "label": "третья"}}}
```

- номер 1…99 → профиль ПК (слово ОСНОВНОЙ = ключ `CLAUDE_CONFIG_DIR` снят) → буква слота сервера
  (`TB_CLAUDE_TOKEN_<буква>`, пусто = слота нет) → метка без почты (`@` — отказ записи);
- строка с браком выбрасывается с названной причиной, остальные живут; слот у двух учёток — снят у обеих;
- выбор строителей: ОСНОВНОЙ → ключ снят; каталог есть → ключ = каталог; **всё прочее → ОСНОВНОЙ + WARNING**
  (реестра нет · не JSON · номер не назван · номер не из реестра · каталога нет); пустого значения
  ключа нет ни на одной дороге (профиль без входа, замер 70u);
- обе ветки спавна демона зовут `accounts.apply_builders`; `accounts.py` внесён в `_ORCH_RUNTIME`
  (проверка логикой `test_orch_runtime_covers_every_top_import_of_daemon`: пропусков 0);

**Сервер (`vps_token_install.py`).** Секрет по-прежнему не выходит наружу ни одним каналом.
- слоты любой буквы (`slot_name`, закрытая форма; хвостовой перевод строки отбит `fullmatch`);
- `--probe-slots` меряет действующее и КАЖДЫЙ слот, названный в файле (разведка отдаёт имена и длины,
  без значений); время сброса — словами поставщика и только на 429;
- `--slot X`: годовой токен только в `TB_CLAUDE_TOKEN_X`, одна проба этого слота; 401/иное → возврат
  файла из копии; 429 → оставлен; демон не перезапускается;
- `--use X`: значение слота X копируется в действующее СЕРВЕРНОЙ программой (в stdin идут только
  имена). Ход: разведка → идёт заход → стоп словами, файл не тронут → копия с датой рядом → запись →
  ОДНА проба по файлу → отказ (401, 429, иное): возврат копии, демон не тронут → 200: повторная
  проверка «не начался ли заход» → ОДИН рестарт. Копия не удаляется никогда;
- `X` — буква или номер учётки из реестра.

**Отступление от порядка задания — названо.** Задание: «копия, рестарт, одна проба, отказ — откат».
Сделано: копия → проба → рестарт только при 200. Проба читает тот же файл, с которым поднимется
демон, поэтому меряет то же самое, но отказ не стоит второго рестарта «обратно». Слово владельца
тратит не больше одного рестарта; второй бывает только когда сам рестарт не поднял демона — это
подъём обратно на прежнем значении.
