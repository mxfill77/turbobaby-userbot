# Решение развилки смоука #274 шаг 7: вариант Б — канон строк J/доставки вставляет ТОЛЬКО КОД

Дата: 2026-07-23. Контекст: развилка артефакта
`2026-07-23-smoke-verbatim-quote.md` (живой смоук цепи #274 failed 2/2 —
конфликт дедупа #365 с инвариантом #92 «строка J дословно»).

## Решение владельца

**Вариант Б**: строку J и строку доставки в клиентском черновике собирать
детерминированно из листа (канонический текст + цифры кодом), LLM их не
перефразирует — как в прайс-блоках `[PRICE_SHEET]`. Инвариант #92 «строка J
дословно» выполняется **по построению**; конфликт с дедупом #365 снимается —
склеивать нечего, строки канонические.

## Что сделано (suggest.py)

1. **Маркерный quote-режим** (одиночная модель, живая цена, без процента —
   путь смоука и доминирующий живой путь):
   - инструкция ЦЕНА (`_quote_marker_note`) больше НЕ несёт цифр — велит LLM
     поставить метку `[QUOTE]` отдельной строкой и цифр не называть;
   - цифры (дословный столбец J + депозит) живут ТОЛЬКО в служебных скобках
     `<<<QUOTE>>>` (в промпт не текут) и в финал вставляются КОДОМ.
2. **`compose_quote_draft`**: дедуп #365 «все денежные числа уже в тексте →
   не дублируем» СНЯТ. Метка `[QUOTE]` → вставка в точку метки (остатки
   продублированных меток вычищаются); метки нет → блок хвостом (fail-safe).
   Канон доходит клиенту ВСЕГДА.
3. **`compose_delivery_draft`**: денежный дедуп СНЯТ (живой смоук: sonnet-5
   взял «590 бат» из few-shot FAQ «Найхарн», дедуп пропустил склейку — строки
   доставки не было). Единственный легитимный пропуск сохранён: тариф, УЖЕ
   названный клиенту в этом окне и не изменившийся (живой ТЕСТ-10,
   sales-method §2).
4. **make_system_prompt**:
   - новая ветка ЦЕНОВОЙ ПОЛИТИКИ для маркерного режима («цена уже посчитана,
     код вставит на место [QUOTE], цифр не называй, отписку не пиши») — иначе
     generic-политика толкала бы LLM в «уточню цену и вернусь»;
   - Этап 2 (зона определена): «подтверди доставку БЕЗ ЧИСЕЛ — стоимость сам
     НЕ называй, ни из FAQ, ни из примеров; строку вставит КОД».

Пути вне решения НЕ тронуты: процент (сумма вплетена в инструкцию — LLM обязан
видеть цифры), несколько моделей bullets, min/sanity/none-фолбэки, legacy-ноты
из IPC (без метки [QUOTE] → прежняя generic-политика).

## Известная цена решения

- Если LLM вопреки промпту всё же выдаст цифру (галлюцинация из FAQ), в
  черновике возможен дубль (парафраз + канон) — канон при этом ГАРАНТИРОВАН;
  модератор может подрезать руками. Дубль в живом пути маловероятен: цифр в
  промпте нет.
- Редкий путь «N юнитов + пара поколений XMAX» (bullets + блок) остаётся с
  видимыми LLM ценами в bullets — там дубль возможен по той же цене; вне
  скоупа развилки, при появлении в живых окнах — отдельная задача.
