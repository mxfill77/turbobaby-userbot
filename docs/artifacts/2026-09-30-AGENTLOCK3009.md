## 5. Как применить (серверная полоса, словом владельца) и откат

**Применение.** Ветка стоит прямо на 0772f84, а живой `main` = 0772f84. Файла
`tests/test_agents_lock.py` в живом дереве нет, поэтому fast-forward пройдёт без конфликта.
```
cd /root/turbobaby-manager-bot
git rev-parse --short HEAD                      # обязано быть 0772f84, иначе остановиться
git fetch origin agents-lock-3009
git merge --ff-only FETCH_HEAD                  # HEAD → 9093784
venv/bin/python3 gate.py                        # живой гейт со своим .env
systemctl restart splinter.service              # ОДИН рестарт: self-update у сервера нет
```
Цена рестарта: стираются буферы в памяти (фото, ожидания, TTL 3 ч). Как проверить после рестарта:
- на первое сообщение в «Агентах» в `splinter.log` ложится строка `Splinter [agents] приём -1003999596406 uid=…`
  (отсюда берутся user id менеджеров — неизвестное №1 из AGENTGROUP3009);
- голос в группе вне карты даёт строку `ЗАМОК ГОЛОСОВЫХ: группа …`, а строки `Transcribed:` после
  неё нет.

**Откат (ничего не удаляя):**
- **полный:** `git revert 9093784` + рестарт. Это возврат к сегодняшнему дню, **то есть к открытой
  двери голосовых** в незнакомых группах — называю прямо;
- **частичный:** убрать только строку `-1003999596406: "agents"` из `GROUPS` (правкой, коммитом) +
  рестарт. Группа снова вне карты: текст и фото молчат, как до правки, а голос из неё теперь ловит
  замок. Замок остаётся.
