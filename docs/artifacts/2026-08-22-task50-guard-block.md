## 4. Гипотеза владельца: закрасился ли гард на СЛОВАХ из блока запретов задания

**В названной форме — НЕТ. По сути — ДА, но слова не те и не в том файле.**

**Текста задания гард не видит вовсе.** Это PreToolUse-хук, его вход — три поля:

```python
2615:        data = json.load(sys.stdin)
2618:    if (data.get("tool_name") or "") != "Bash":
2619:        _defer()
2620:    cmd = ((data.get("tool_input") or {}).get("command") or "")
2621:    cwd = data.get("cwd") or PROJECT
```

`tool_name`, `tool_input.command`, `cwd` — ТЗ среди них нет ни в каком виде, и
объектом блока в журнале записана команда, а не текст задачи.

**Но сработал он действительно на СЛОВАХ, а не на попытке действия.** Слова лежат
в собственной фикстуре исполнителя `_scratch_works_buf/measure.py`:

| строка | что там | чем стало для гарда |
|---|---|---|
| 141 | `def set_fleet_oil(s, **k):` — метод ФЕЙКОВОГО моста | хит `set_fleet_oil` |
| 39 | `BIKE = "NMAX 155 GREY 5960"` | объект «байк NMAX 155 GRE» |
| 110 | `{"name": "NMAX 155CC GREY PHUKET 5960", "mileage": "15600", …}` | число «пробег 15600» |

`def` — это объявление, то есть противоположность вызову. Докстринг того же файла:
«Фикстуры дословные, из `splinter.log`… **Ничего никуда не пишет: мост фейковый,
сеть и LLM замоканы**», и он сам ставит `BRIDGE_URL=http://x`, `BRIDGE_TOKEN=x`,
`PRETOOL_NOPUSH=1`, `PRETOOL_TEST_RUN=1`. Ни одной клетки записано быть не могло.

**Доказательство, что гард читал ФАЙЛ, а не команду:** в строке команды нет ни
`set_fleet_oil`, ни `NMAX`, ни `15600` — а в карточке есть все три. Значит `blob`
собран из текста скрипта.

**Почему не спас признак тестового прогона.** `_is_test_script` (1511–1537) знает
ровно три приметы: `.py` внутри `/tmp/claude-*/…/scratchpad/`, внутри `/tmp/tb_scratch/`,
либо `_dryrun`/`_test` в имени файла. Каталог `_scratch_works_buf/` не подходит ни под
одну — а положить временное именно туда **предписало само ТЗ** («временное класть
в `_scratch_works_buf/`»). `PRETOOL_TEST_RUN=1` скрипт ставит внутри себя, то есть
уже после того, как хук вынес решение.

**Замок против подстроки в гарде есть — и он не сработал.** Комментарий 1498–1504
запрещает ровно этот исход:

```python
1498:        # ГРАНИЦА УЖЕСТОЧЕНИЯ — ОБЪЕКТ ОПЕРАЦИИ, а не само красное слово. Жёстко закрываем только
1499:        # то, что похоже на НАСТОЯЩУЮ запись: объект в команде есть, а пометки ТЕСТ у него нет —
1500:        # тогда молчание о сущности и правда означает отказ. Если объекта нет вовсе (голое
1501:        # упоминание имени операции в тексте, `print('set_fleet_oil')`), решать нечего… Иначе
1503:        # гард начал бы отказывать ПО ПОДСТРОКЕ, ровно против правила «судить по ДЕЙСТВИЮ,
1504:        # а не по слову в команде».
```

Замок держится только пока у упоминания НЕТ объекта. Здесь объект дала фикстура —
и дала потому, что **пункт 6 того же ТЗ требовал регресс на ЖИВОМ формате из журнала**.
Требование задания само изготовило улику, по которой гард закрыл заход.

Побочно замечено, не чинилось: комментарий 2642 утверждает «ТЕСТ-сущность и
неизвлечённая сущность идут прежним мягким путём — карточка с «да»», а ветка
1497–1507 (правка 01.08.2026) неизвлечённую сущность с объектом закрывает жёстко.
Комментарий отстал от кода.
