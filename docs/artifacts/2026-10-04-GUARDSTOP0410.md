## Правило на класс «форма не разобрана» (одно; кода не меняю)

**Цель интерпретатора и адрес канала судятся после литерального раскрытия строки и только по нему.**
- Раскрытие берёт из самой строки ровно четыре литерала:
  - присваивание `X=<литерал>` или `$x="<литерал>"` до использования;
  - `cd <литерал>` — база относительных путей последующих сегментов;
  - тело heredoc `<<'EOF'` или here-string PowerShell `@'…'@`: поданное интерпретатору — это код; записанное в `F` (`cat > F`) — это содержимое `F` для запуска `F` дальше в той же строке;
  - PowerShell `& <путь>` — вызов `<путь>`.
- Целью python считается только аргумент интерпретатора (первый не-ключ после python и его ключей; `-c`/`-` с телом). `.py` в аргументах других команд (`git add`, `grep`, `scp`) — данные.
- Раскрытая форма судится **ровно как явная**: тот же вид, тот же объект.
- **Что не раскрылось** (цикл, `$(…)`, переменная без литерала, переприсваивание, склейка `$t.py;`), получает пометку «гард кода не видел» (`_PY_UNSEEN` → отказ). Ни «без внятной цели», ни тихого прохода.

Чем правило закрывает класс (в обе стороны):
- **Ложное красное становится решением явной формы:** R04, R06, R08, R11, R12, R14, R15, R17, R19 — по видимой строке. R01, R05, R10, R16 — по форме хвоста, это вывод. R09 и R13 уже закрыл `d97e206b`.
- **Ложное зелёное становится красным:** P1, P3, P5, P6 ниже.
- **Вне правила остаётся R02:** удалённый `python3 /root/…py` — цель на другой машине, локально её не прочитать. Канон одним вызовом `scp`+`ssh` с явным локальным путём проходит уже сегодня.
