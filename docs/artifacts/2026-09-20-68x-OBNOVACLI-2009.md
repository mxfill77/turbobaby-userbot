## 2. Обновление: НЕ СДЕЛАНО, и это названная законная ветвь

Задание разрешает: «Обновить нельзя — назвать причину адресом и остановиться». Причина
названа адресом, и она **не техническая, а правило полосы**.

**Способ, которым он ставился, — `npm install -g`.** Тот же способ обновления — одна команда:

```
npm install -g @openai/codex@latest
```

Она требует двух вещей, и обе запрещены этому заходу его собственной рамкой запуска
(строка задания: «НАСТОЯЩЕЕ КРАСНОЕ … выход за пределы проекта, сеть кроме git/Bridge/Telegram»):

1. **сеть к реестру `registry.npmjs.org`** — это не git, не Bridge и не Telegram → красное `network`;
2. **запись за пределы проекта** — в `C:\Program Files\nodejs\node_modules\@openai\codex`,
   то есть вне `D:\turbobaby-bot` → красное `outside`.

Обхода не искал и не делал: локальная установка в дерево проекта была бы именно обходом
(и дала бы второй codex мимо PATH, то есть мимо живой двери `shutil.which("codex")`).

**Чего в причине НЕТ — и это важно для того, кто будет исполнять руками.** Двух ожидаемых
препятствий здесь **не оказалось**, оба сняты замером:

* **Права администратора НЕ нужны.** Сессия не повышена
  (`WindowsPrincipal.IsInRole(Administrator)` → **False**, пользователь `mxfillpc\mxfill1`), но

  **`FullControl / Allow`** (`Get-Acl`). Обычной консоли достаточно.
* **Каталог и пакет на месте** — ставить «с нуля» не придётся, это апгрейд поверх.

**Версия до: 0.151.0. Версия после: 0.151.0 — обновления не было.**

**Где её можно было бы задать — три места, по убыванию близости к нашему коду:**

1. **`--codex-model <модель>`** — наша собственная ручка, уже доехавшая до `-m`. Правки кода
   не требует вовсе у дверей 2–3 (дописать флаг в `retry_argv` / в ручной вызов); у двери 1
   требует одной строки в `pc_orchestrator.py:11293`.
2. **`-m, --model <MODEL>`** — флаг **самого CLI v0.151.0**: он **уже есть в этой версии**
   (`codex exec --help` → `-m, --model <MODEL>  Model the agent should use`). То есть
   прибить модель можно **не обновляя CLI вовсе** — если знать имя модели, которую 0.151.0 умеет.
3. **`-c model="…"`** — перекрытие настройки у того же CLI (`codex exec --help`, раздел примеров:
   `-c model="o3"`), и **собственный конфиг codex** (файл настроек CLI). Конфиг этим заходом
   **не читался и не правился** — запрет задания на чтение конфигов; поэтому откуда именно

Имя модели, которую v0.151.0 умеет, этот заход назвать не может: оно читается либо из реестра
моделей их стороны (сеть), либо из конфига CLI (запрет). Поэтому п.2 не подменяется «а давайте
просто прибьём модель» — подстановка наугад дала бы второй 400 и потраченную пробу.
