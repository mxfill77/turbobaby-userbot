## 0. Тело и признак сделанности

Тело — **≈4000 символов**. Оценка по абзацам, напечатана первой строкой захода. Хвост цел, адрес виден.

**0б.** Ни прибор, ни вывод, ни этот файл формы не печатают. Идут только вид, «целая/кусок», длина совпадения, длина значения, классы знаков (`l` строчные, `u` прописные, `d` цифры), `sha256(совпадение)[:8]`, адрес `файл:строка` и дата файла. Текст ошибки моста печатается через вычёркивание форм. Сверка с общедоступными префиксами печатает **номер** кандидата, а не строку.

**0в.** Файл результата один — этот. В имени временного места нет слов адреса.

**0г.** За 17.09 до захода в `docs/artifacts` лежало шесть файлов: 62-p, 62-q ×2, 62-r, 62-s и 62-t. На п.2–п.4 **не отвечает ни один**. 62-t доказал **возможность** утечки: стенд на выдуманных образцах, §2. Сохранённое отправленное он не проходил. Работа начата с нуля.

- **Найденного, требующего смены ключа, нет.** Н1 и Н2 — общедоступный префикс без секретных знаков. Н3 — чужой входящий ответ, не наш ключ.

Закрыть НЕИЗВЕСТНО по ним можно только чтением самих тем (Аудит, сводка контура, заявки), а это живые чаты, отсюда под запретом. Второй путь — принять довод по источнику для Аудита.
