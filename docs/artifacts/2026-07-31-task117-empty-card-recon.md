### ДОСЛОВНОЕ МЕСТО, ГДЕ ПРИНИМАЕТСЯ РЕШЕНИЕ

`pretool_guard.py:2642-2656` — само правило. Решает **одна строка 2656**:

```python
def card_gate(kind, obj, num=""):
    """ЕДИНОЕ ПРАВИЛО КАРТОЧКИ, общее с полосой сервера (29.07.2026) → True = карточка, False = журнал.

        • ОБЪЕКТ обязателен ВСЕГДА. Нет объекта — признак сработал на ПОДСТРОКЕ, а не на действии
          (живой пример суток: `echo "---SCHTASKS XML---"` внутри `ls`, где слова Планировщика нет
          ни в одной командной позиции): показывать владельцу нечего, идёт строка в журнал.
        • ЧИСЛО карточку НЕ гейтит НИКОГДА. Оно есть там, где операция несёт его ПО СВОЕЙ ПРИРОДЕ
          (сумма, пробег, количество целей, версия, PID), и честно пусто там, где не несёт.
        • Hard-блок и секреты (_HARD_CARD) спрашивают всегда — как и было. Деньги тоже.
    ...
    return bool((obj or "").strip()) or kind in _HARD_CARD
```

**Правило «нет объекта — нет карточки» НИКОГДА не было безусловным.** После `or` стоит исключение,
и оно и есть ответ (`pretool_guard.py:2518`):

```python
_HARD_CARD = ("unknown", "env", "edit_secret", "read_secret", "py_write", "live_sheet")
```

Поведение из правила делает `card_decision`, `pretool_guard.py:2676-2684`:

```python

**ЖИВОЙ ЗАМЕР (вызовы живого гарда ПК, ничего не исполнялось):**

| вызов | результат |
|---|---|
| `card_gate("kill", "", "")` | `False` → журнал |
| `card_gate("delete", "", "")` | `False` → журнал |
| `card_gate("unknown", "", "")` | **`True`** → карточка |
| `card_gate("py_write", "", "")` | `True`, но `py_write` в `_TOP_TIER` → **`deny`**, не карточка |
| `card_decision("unknown", "", "")` | **`ask`** ← пустая карточка рождается |

Дословный вывод `card_decision("unknown", "", "")` — та самая пустая карточка:

```

**ИТОГ ПО ПУНКТУ.** Пустая карточка рождается не в обход гейта, а **через его исключение**: у видов

они не входят — значит `deny`-ветка (строка 2680), которая как раз и не выписывает безобъектную
карточку, до них не достаёт. Ровно четыре вида могут дать владельцу «Объект: —».
Правило владельца «карточка без объекта не выписывается» держит только `_TOP_TIER`.
