### Шаг 2/7 (`8b7090f`) — «N юнитов ОДНОЙ модели» в quote-блоке
- `suggest._units_count`: детект «пара / два / 2 скутера». Слово-число считается
  только при байк/юнит-контексте или явной модели; «два дня» — срок, исключён
  хвост-проверкой; «цифра+существительное» самодостаточна; разные модели — это
  НЕ N юнитов одной.
- `build_pricing_note`: к блоку ЦЕНА дописывается пометка «за каждый» (цена И
  депозит per unit из Bridge). Общий итог за N штук **не считается/не
  выдумывается** — числа только из quote (инвариант цена/кап не ослаблен).
- Голден «пару скутеров xmax 16-24 июля» + парафразы RU: цена за каждый
  (790/939), депозит за каждый (5000/7000); выдуманных сумм (1580/1878/10000/
  14000) нет. Детект-тест: реальная фраза + парафразы RU/EN + негативы (одна
  единица / «два дня» / приветствие / только депозит / разные модели).

## Что осталось (шаги 4–7)
- **«N юнитов одной модели» — сквозная протяжка.** Детект и пометка «за каждый»
  сделаны в `suggest` (шаг 2), но нужно провести N-юнитов через strategy-путь
  перегенерации (`moderation_core` → regen) и убедиться, что кумулятив-директивы
  окна (шаг 3) с ним совместимы.
- **Гард наличия.** Явная проверка доступности/наличия модели (нет модели / нет
  свободных юнитов на даты) до выдачи цены — сейчас quote-блок молча даёт цену,
  даже если наличие не подтверждено. Нужен гард, отражённый и в промпте, и в
  пост-чеке.
- **Сквозные голдены.** Голдены end-to-end по всему strategy-пути
  (`process_reply → regen → suggest`), а не только по отдельным функциям:
  реальная фраза клиента → кумулятив директив окна → цены кодом → гард наличия →
  финал без выдуманных сумм. По правилу-классу CLAUDE.md — дословные живые фразы
  клиента + парафразы RU/EN в позитивах и контрпримеры в негативах.
